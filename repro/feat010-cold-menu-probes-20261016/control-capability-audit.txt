Evidence limits
This code path establishes that the installed observer has a built-in synchronous stop-after-timeout mechanism; it does not prove that XRoar's current GDB stub responds successfully to SIGINT, that its GUI is visible to the user during the call, or that a transient visual defect persists until the post-interrupt snapshot. Parent should treat those as outcomes of the already-approved bounded manual case, not as established facts from this static audit. No separate capability qualification proposal is needed before that case; no runtime result is claimed here.
