Review: not ready to freeze

1. Stop classification is incomplete (`options-runtime-command.js.txt`, `resume`, lines 32-60). `fired` is set when the 4-second SIGINT timer fires but never read. For an expected callback, a SIGINT stop at the expected numeric PC is accepted as a callback without checking the GDB stop reason. For the final `resume(null)`, an early natural stop is accepted as the witness stop. Preserve the raw PC/state on every stop, but classify a timer interrupt or non-breakpoint early stop as incomplete and stop; only the expected breakpoint can advance the callback sequence, and final capture must establish the bounded unpaused interval.

2. There is a cancellation race in the same timer. Once it enters `host(...)`, setting `active=false` after `continue_exec` returns cannot cancel the already-started WSL command. It can SIGINT GDB after a natural breakpoint has stopped it. The script awaits the timer before issuing another GDB command, which avoids concurrent GDB commands, but does not prevent the late signal. Resolve this before dispatch or make a raced stop incomplete.

3. The deadline guard does not cover all bounded host calls. `binding()` reserves only 3 seconds although `host()` can wait up to 10 seconds; the final witness snapshot invokes it immediately before cleanup. The event/done/publish state read also calls `host()` without a preceding budget check. These paths can consume the stated 8-second cleanup reserve and overrun the shared 45-second phase. Guard them for their actual maximum call time plus cleanup reserve; if that budget is unavailable, stop incomplete before starting the call.

Native input and guest state handling are otherwise consistent with the card: the script contains no input injection or guest-memory writes, and it verifies the capsule before the cold launch, then binds the full resident and presentation bytes before using mapped execution labels. Dispatch still requires the parent to obtain the user's ready-to-operate confirmation before launching; this script starts immediately and has no interactive prompt.
