FEAT-011 connector generator hardening Deferred

Two nonblocking safeguards for the map-specific EXTRA connector generator.

Deferred improvements

  1. Restrict the write destination. The generator accepts a map path on the command line and its write mode writes to that path. The approved FEAT-011 map edit is limited to tiled/coco-extra-screen.tmx. A future hardening change can make write mode reject any other resolved destination, including a path that redirects outside the repository. This is not a blocker for the current approved source-preparation boundary.
  2. Join the slot and marker checks. The generator checks the expected marker cells and separately calculates endpoints from slot numbers. The current recorded values align: slot 0 targets marker cell (33,22) at pixel (272,176), and slot 11 targets (37,16) at (304,128). A future oracle can derive each endpoint from its specific marker cell and assert the full one-to-one mapping, so changing either ordering cannot leave both checks passing independently. This is not a blocker for the current approved source-preparation boundary.

Disposition

These safeguards are deferred hardening. They do not change FEAT-011's approved source-preparation scope, acceptance behavior, or authorization state. Revisit if the generator is generalized, the map's marker layout changes, or the user reprioritizes these protections. No source was changed and no generator, test, build, or runtime check was run for this backlog record.
