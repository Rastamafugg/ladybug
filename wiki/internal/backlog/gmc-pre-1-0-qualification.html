GMC qualification before 1.0 Deferred

Review remaining GMC emulator and hardware qualification before the official 1.0 release.

Current evidence

The user reports the game appears to work during interactive play in XRoar. The latest complete-profile ROM is 65,536 bytes with SHA-256 b32560c32f61da6d3da55fb078825b6c4002a15a9de28be44de6c3da63d6a668; its source-build receipt matches 265 current source inputs and 650 generated artifacts, and source-documentation verification passes.

The historical MAME 0.220 paired marker pass is for the highscore-test candidate ROM with SHA-256 cba9070ee43b9d05f4697e097394691b38f41a74966bea778e5cc55b147270d7. MAME 0.220 also ran the latest complete-profile ROM for 4.016667 emulated seconds and exited 0, but the final frame was solid black rather than the expected coherent ATTRACT/startup image. The original four-second visual marker target failed. Authorized diagnosis confirms the capture ended before first visible ATTRACT at 4.333333 emulated seconds; the same ROM displays coherent animated ATTRACT in an eight-second run. A complete rebuild is byte-identical. See the diagnosis receipt. The run receipt and frame are retained. The full automated complete-profile XRoar verifier has a separate 10-second timeout before start-preempts-ranking-load; this does not identify a cause. XRoar's parity-based SCS handling cannot distinguish $FF40 from $FF50, and physical GMC-compatible hardware has not been tested. See BUG-113 and BUG-115.

Items for pre-1.0 review

  1. Review complete-profile startup latency before 1.0: first visible ATTRACT was observed at 4.333333 emulated seconds, missing the original four-second target by 0.333333 seconds. Decide whether to retain that target and approve a focused startup optimization, or revise the target with explicit approval. The unchanged ROM already boots successfully in an eight-second MAME capture; natural MAME input and audio remain unverified. The prior HST marker result is separate.
  2. Decide whether to diagnose the automated start-pre-emption timeout in BUG-115. Its proposal remains unapproved; the timeout alone does not establish a gameplay defect.
  3. Decide whether direct physical GMC-compatible hardware qualification is required for 1.0, because XRoar cannot discriminate the two even-address aliases.

These are deferred review candidates, not newly approved implementation scope or established release blockers. BUG-113 and BUG-115 remain Deferred until the pre-1.0 review assigns any required work.
