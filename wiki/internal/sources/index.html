Citations and notes for raw references under docs/: arcade ROM, schematics, reference books, prior-art source.

Reference books

  • Tepolt — CoCo 1/2 (The Book)

    MC6809E, addressing modes, SAM/PIA, VDG, cartridge connector. Most of it still applies to the CoCo 3.

  • Tepolt — CoCo 3 addendum

    GIME (ACVC), MMU, palette, hi-res modes, ACVC IRQ sources, reset init. Addendum to "The Book".

Prior-art code

  • Dungeons of Daggorath — cartridge source

    1983 cartridge port. Mined for 6809 idioms. DoD-derived patterns we adopt are in coding-conventions; ones we explicitly skip are in lessons-learned.

Lady Bug arcade

  • Arcade reference (web ingest)

    Web sources consulted to seed game/overview. Wikipedia, Pixelated Arcade, C64-Wiki, bitvint.com.

  • Arcade graphics extraction

    Pipeline pulling tile/sprite data + palette from the original arcade ROM via the MAME ladybug driver.
