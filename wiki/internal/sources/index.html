Reference books

  • Tepolt — CoCo 1/2 (The Book)

    MC6809E, addressing modes, SAM/PIA, VDG, cartridge connector. Most of it still applies to the CoCo 3.

  • Tepolt — CoCo 3 addendum

    GIME (ACVC), MMU, palette, hi-res modes, ACVC IRQ sources, reset init. Addendum to "The Book".

Prior-art code

  • Dungeons of Daggorath — cartridge source

    1983 cartridge port. Mined for 6809 idioms. DoD-derived patterns we adopt are in coding-conventions; ones we explicitly skip are in lessons-learned.

External hardware

  • External sound cartridges

    Tandy Speech/Sound, SuperSprite FM+, Multi-Pak routing, and Orchestra-90 CPU-offload assessment.

  • Programming the Game Master Cartridge

    GMC bank limits, SN76489 timing and mux setup, MPI routing, emulator commands, VGM guidance, and Ladybug comparison.

  • Arcade graphics extraction

    Pipeline pulling tile/sprite data + palette from the original arcade ROM via the MAME ladybug driver.

2026-09-27 — Boot compression source review

Reviewed candidate src/gmc_bootstrap.s descriptor copy/staged-audio/decoder paths, src/audio_runtime.s audio_init_impl, scripts/build_sparse_sprites.py pack_candidate_banks/write_loader_include, and scripts/gmc_lzss.py compress/decompress. The codec uses 12-bit backward distances and lengths 3–18 with eight flag bits, and its host encoder computes a minimum-byte parse within that fixed format. Current loader special-cases the fourth stream for post-all-RAM audio expansion. Revision, measurements, constraints and proposed generated stream identity; memory/phase findings. No runtime source changed in this review.
