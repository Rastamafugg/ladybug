Internal · tooling

Tiled MCP read-only surface internal

Protocol design for exposing Tiled project context and safe inspection tools.

Decision status

TOOL-003 is Proposed. This page records the Ladybug-specific rationale. The full contract is maintained in D:\retro\tiled-mcp\docs\mcp-read-only-surface.md. No MCP implementation is authorized until the user approves the exact namespace, schemas, security boundary, and exclusions.

Selected boundary

Use standard MCP resources for raw Tiled files and normalized, read-only views. Use model-controlled tools for parameterized inventory, inspection, reference-graph construction, validation, and dry-run translation planning. Do not create a raw-read tool that duplicates resources/read.

Use a custom tiled:// scheme with configured project aliases and project-relative paths. Do not expose host absolute paths. Canonicalize and contain every path, reject traversal and symlink escapes, preserve SHA-256 provenance, and fail explicitly for malformed or unsupported data.

First surface

  • tiled://project/{id}/manifest — project inventory anchor.
  • tiled://project/{id}/file{?path} — raw text or binary file content.
  • tiled://project/{id}/normalized{?path,view} — bounded JSON views for summary, layers, tilesets, objects, and references.
  • tiled_inventory — filtered deterministic inventory.
  • tiled_inspect — one normalized resource view.
  • tiled_resolve_references — bounded external-reference graph.
  • tiled_validate — generic or target-profile validation without writes.
  • tiled_plan_translation — dry-run target plan with unsupported-feature diagnostics.

Ladybug constraints

A Tiled resource is authored input, not assembly source. A successful normalized read or translation plan does not prove GIME palette correctness, 6809 packing, GMC source capacity, RAM/MMU destination capacity, or visible runtime behavior. The future Ladybug adapter must retain the existing Python oracle and verifier boundaries.

Primary public references: MCP resources, MCP tools, and Tiled JSON map format.
