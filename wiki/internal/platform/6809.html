6809 — Project Notes internal

Ladybug-specific commentary on the MC68B09E. The canonical ISA reference is in release/reference/6809/.

Why we can run fast

The CoCo 3 ships with the MC68B09E — same instruction set as the MC6809E used in the CoCo 1/2, but rated for the doubled 1.78 MHz bus. Ladybug runs at the fast clock because we never enter the BASIC cassette/serial/disk I/O ROM paths. Doubling the clock halves the cost of every cycle-counting decision and brings the 60-Hz arcade frame within easy reach. See timing for the budget math.

Addressing-mode preferences

Catalog of indexed postbytes and TFR/EXG/PUSH/PULL register codes is in registers and addressing modes. For Ladybug, prefer:

  • DP-relative for hot per-frame state. DP is set once at boot and never changes (see coding-conventions §1).
  • PC-relative within position-independent code blocks. A cartridge ROM is naturally position-independent if we discipline ourselves.

Clock-select for Ladybug

Ladybug's reset routine writes anything to $FFD9 to select 1.78 MHz. Writing to $FFD8 would restore 0.89 MHz (needed only for BASIC cassette/serial/disk I/O, which we don't use). See timing for the SAM clock-rate table and lessons-learned for the Phase 1 boot sequence that performs the switch.

SWI as a syscall layer

SWI / SWI2 / SWI3 are candidates for a syscall trap layer (coding-conventions §4). Vectors at $FFFA/$FFF4/$FFF2 are disjoint from IRQ/FIRQ at $FFF8/$FFF6, and BASIC's SWI2/SWI3 use is moot in all-RAM mode. No collision — Phase 1 gate resolution, see lessons-learned.

Caution: SWI at a -trap point makes XRoar 1.10 segfault when it tries to snapshot — see tooling/xroar. Use BRA * as a halt loop instead.

Mnemonic-family anchors

Anchors used by the web/ retro-dev app's instruction-annotation panel. The opcode JSON in web/data/6809-opcodes.json deep-links here per family. Each subsection is intentionally brief; cycle-accurate per-encoding details live in the curated opcode JSON.

Load (LDA / LDB / LDD / LDX / LDY / LDS / LDU)

Loads a register from memory or an immediate. 8-bit forms set N from bit 7 of the result, Z if the result is zero, and clear V. 16-bit forms set N from bit 15 instead. C is unaffected. Indexed and extended variants exist for every register.

Store (STA / STB / STD / STX / STY / STS / STU)

Stores a register to memory. CC effects mirror the load forms.

Effective-address load (LEAX / LEAY / LEAS / LEAU)

Compute an indexed effective address and load it into the destination register without performing a memory access. The common idiom for pointer arithmetic. LEAX and LEAY set Z (zero-result detection — useful for LEAX -1,X loop bottoms); LEAS and LEAU do NOT affect CC.

Branch (BRA / BHI / BLS / BHS / BCC / BCS / BLO / BNE / BEQ / BVC / BVS / BPL / BMI / BGE / BLT / BGT / BLE / BSR / LBRA / LBSR)

PC-relative jumps. Short forms take an 8-bit signed offset (±127); long forms (page-2 prefixed) take a 16-bit signed offset (±32 K). BSR/LBSR additionally push the return PC to S.

Push / pull (PSHS / PSHU / PULS / PULU)

The postbyte selects which registers to transfer, with bit positions (high→low): PC, U, Y, X, DP, B, A, CC. Cycle cost is 5 + 1 per byte transferred. PULS/PULU restore CC if it's in the postbyte mask.

Transfer / exchange (TFR / EXG)

TFR copies source→dest; EXG swaps. Postbyte holds two register codes (high nybble + low nybble). Mixing 8-bit and 16-bit codes is allowed; the manual specifies the conversion.

Return / halt (RTS / RTI / SWI / SYNC / NOP / CWAI)

RTS pops PC. RTI pops a stack frame whose size depends on the E bit in the stacked CC (FIRQ 6 cycles, IRQ/SWI/NMI 15). SWI is a software trap vectoring through $FFFA-FFFB — note the XRoar 1.10 segfault when SWI is at a -trap point. SYNC halts the CPU until an interrupt. NOP is a 2-cycle no-op. CWAI ANDs an immediate into CC then halts until interrupt.

CC manipulation (ORCC / ANDCC)

Bit-wise OR / AND an 8-bit immediate into CC. Used to set or clear mask bits — e.g. ORCC #$50 to mask both IRQ and FIRQ during a critical section.

Arithmetic and bit (CLR / INC / DEC / TST / NEG / COM / ASL / ASR / LSR / ROL / ROR / ADD / SUB / CMP / AND / OR / EOR / BIT / MUL / SEX / ABX / DAA / ADC / SBC)

Standard 6809 arithmetic, logical, shift, and bit-test instructions. See condition codes for the precise CC effects per family.
