Sound — project plan internal

Arcade-reference capture and a bounded GMC SN76489 implementation.

Hardware reference (selector switch, DAC paths, PB1) is in release/reference/coco3/sound.

Selected planning direction

Proposed in RSCH-001: use the Games Master Cartridge's 4 MHz SN76489 for the shipped sound implementation. The original arcade uses two equally mixed 4 MHz SN76489 chips, so fidelity work is a measured two-chip-to-one voice reduction rather than PCM sample playback.

  • Capture MAME's final 48 kHz mono mix and every write to both arcade PSGs under deterministic input plans.
  • Inventory and force isolated, natural-sequence, overlap, interruption, and explicitly silent cases.
  • Reconstruct pitch, volume, noise, timing, and channel ownership from register traces; WAV alone is not sufficient.
  • Compile effects and melodies to compact 60 Hz command records for one GMC PSG.
  • Dispatch semantic game events through a bounded foreground service after render publication. Do not sequence sound in the IRQ.

The research target is a worst 60 Hz service of at most 800 6809 cycles and 12 changed-register writes, no writes when unchanged, no more than 1536 cartridge-source bytes for engine plus command data, and no more than 24 direct-page bytes. These are proposal limits, not measured results. Exact placement and limits require a refreshed map after FEAT-002 integration; the resident and bank-3 windows are currently full.

GMC programming guide comparison

The ingested GMC programming guide confirms the 64 K bank limit, almost-16 K usable bank windows, 4 MHz SN76489 target, write-only sound interface, 32-oscillator-cycle write spacing, cartridge audio mux requirement, and power-on mute requirement. These facts reinforce FEAT-006's command-stream and reset design.

  • Ladybug intentionally uses boot-time bank selection and RAM publication; it does not bank switch during gameplay.
  • The guide's MPI slot-routing path is for non-ROM programs and is not a dependency of the shipped GMC image.
  • The guide's VGM/raw playback path is retained as an offline import or comparison option. The runtime remains semantic command records compiled from arcade PSG traces.
  • The guide names $FF40/$FF41, while Ladybug currently uses the CoCo 3 aliases $FF50/$FF51. XRoar accepts the parity-based aliases, but existing MAME 0.220 evidence requires the primary addresses. This remains an emulator and physical-hardware compatibility gate.

FEAT-006 must explicitly verify fixed write spacing without status polling, cartridge-SND mux initialization, and complete muting across cold boot, warm reset, replacement, explicit stop, and game-over. This source ingest does not authorize changing the current address constants.

External sound offload candidate

Preferred path after XRoar source review (2026-07-26): use the SN76489 already present in the Games Master Cartridge. The delivered Ladybug image already requires the GMC, whose hardware and XRoar model include one 4 MHz SN76489. Writes to any odd SCS address program sound; Ladybug can reserve $FF51, alongside its existing even-address $FF50 bank-select convention. This provides three autonomous square-wave voices plus noise, matches one of the arcade board's two SN76489 chips, and requires neither an MPI nor a new XRoar device.

Optional expansion architecture: use another autonomous PSG or FM cartridge through a CoCo-3-compatible Multi-Pak Interface. The 6809 would enqueue semantic events such as dot, bonus, death, and stage clear. A bounded foreground service would translate only new events or note boundaries into sound-chip register writes. Tone, noise, envelope, and FM waveform generation would then continue in cartridge hardware without sample-rate interrupts.

This removes the continuous DAC/PB1 production cost, but not every audio cost: the game still owns event arbitration and, unless the cartridge has its own sequencer, melody note scheduling. Those duties can run at 30 or 60 Hz and should require only a small bounded number of writes. No sound work belongs in the Vbord handler beyond publishing or consuming one queue flag.

  • Best original-era offload: Tandy Speech/Sound Cartridge 26-3144/26-3144A. Its PIC7040, AY-3-8913, and 2 K RAM accept stored sound or register strings in eight buffers; one command can execute a buffered effect. It is therefore the only investigated option that offloads both waveform generation and short effect sequencing. It uses $FF7D-$FF7E and the cartridge SND input. Most units require the documented 1.78 MHz CoCo 3 modification; availability and aging hardware are release risks.
  • Best modern candidate: SuperSprite FM+. Its YM2149 provides three PSG tone channels plus noise/envelope, and its YM2413 provides autonomous FM voices. It supports MPI-mode $FF5x addressing. The chips sustain sound after register writes, but the board does not provide a documented independent music CPU, so Ladybug must still issue note/effect changes. Audio is delivered through the board's A/V path, not assumed to use the CoCo's cartridge-SND selector.
  • Reject Orchestra-90 for CPU relief. Its two write-only 8-bit DACs at $FF7A-$FF7B still require the 6809 to stream samples at an audio rate. It improves resolution and stereo output, not processor headroom.

The current GMC bootstrap uses SCS register $FF50, while the runtime subsequently executes from RAM. With an MPI, boot must leave SCS routed to the Ladybug slot until all GMC payloads are copied, then route SCS to the external sound slot and leave it there. The MPI independently selects CTS/CART and SCS through $FF7F. Exact SuperSprite register addresses, A/V cabling, SCS decoding, and coexistence with the GMC bank register require a physical-board proof before this becomes a release requirement.

Recommended product policy: retain internal sound as a minimal fallback or allow silence, make GMC SN76489 the primary enhanced backend, and detect/configure other hardware only as optional backends. Do not make scarce original hardware mandatory. For arcade character, the GMC SN76489 is exact chip-family prior art; YM2149/AY-3-8913 PSG is closer than YM2413 FM when an alternate cartridge is used.

Selector setup gotcha

From a cold reset, BASIC sets up usable defaults for the audio selector; we will not rely on those — we'll initialise both PIAs explicitly.
