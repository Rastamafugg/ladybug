    24×24 map, dots, four-state rotating gates, dynamic collision, renderer, and MAME capture workflow.

  • Scheduler (candidate)

    TCB-based round-robin sketch from DoD. Decision deferred until the main loop reaches implementation.

    Hardware quirks, register gotchas, patterns to avoid, explicit decisions. Append-only.

    Four-workstream initiative: tester ROM + live FB renderer + memory regions + mode/pattern matrix.

    Implemented custom JSON-RPC server inside XRoar. Preserved but deferred while game development uses gdb-mcp.
