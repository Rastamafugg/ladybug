Assembly and Runtime Glossary internal

Canonical meanings for source, memory, rendering, delivery, and evidence terms used by DOC-002.

Authority and source terms

Authored source
A version-controlled assembly, Python, asset, or configuration input changed by a maintainer. A listing, map, generated include, or rendered browser is not authored source.
Canonical definition
The single hand-authored semantic definition for a term, routine, structure, or ownership contract. Generated symbol presence alone is not a canonical definition.
Generated reference
Disposable revision-bound HTML produced from source, listing, map, configuration, and hashes under build/source-reference/.
Routine contract
Purpose, inputs, returns, clobbers, memory reads and writes, side effects, invariants, callers, callees, and material timing or size constraints.
Basic block
A straight-line control region entered at its first instruction and exited by branch, call, jump, return, or fall-through. It inherits its owning routine contract.

Memory and delivery terms

Assembled address
The address lwasm assigns to an emitted source span. In raw output it is not necessarily the same as a file offset because ORG does not materialize gaps.
Cartridge-staged address
The cartridge source or temporary CPU window used while the bootstrap transports bytes. It is distinct from both the assembled identity and stable runtime destination.
Runtime destination
The stable virtual address and, where relevant, physical page from which code or data is consumed after boot publication.
PAR5 scope
The interval during which one selected physical page owns virtual $A000-$BFFF. Every pointer into that window expires when PAR5 changes.
Authoritative state
The logical record whose value controls behavior. Pixels, save-under bytes, and generated caches are projections unless explicitly named as authorities.

Rendering and evidence terms

Render intent
A compact request describing logical visual work that the central BACK compositor must apply.
Framebuffer owner
The persistent A or B surface selected as FRONT or BACK for one transaction. Owner identity is metadata, not a causal timing explanation.
Publication
The IRQ-time act that makes one fully composed PENDING framebuffer visible. Drawing into BACK is not publication.
Evidence dimension
One of structural, representation, delivery, runtime reachability, visible output, or timing. Each dimension is independently pass, fail, missing, or stale and is bound to an artifact hash.

DOC-002 controlled vocabulary. Add a term only when its meaning is project-specific or materially non-obvious.
