Selected architecture and capacity proof

The approval brief's statement that draw_perimeter_box uses a five-scanline stride is corrected as execution detail. Its row * 5 followed by a one-byte shift into the high half of D computes row * 5 * 256, which equals row * 8 * 160. The incremental path is already aligned and is read-only for this ticket. The defect is confined to synthesize_perimeter_reset and the Python generator/oracle, which literally compute row * 5 * 160 and limit most cells to five rows.

The selected reset program retains physical page $20, the low-RAM gateway, PAR5 ownership, and the existing native-store protocol. It emits all eight authored rows at $2000 + row * 8 * 160 + column * 4. Consecutive changed bytes are greedily encoded with the verifier-supported six-byte LDD #value16/STD address form; residual bytes retain five-byte LDA #value8/STA address. This is representation packing, not a new runtime abstraction.

At checkpoint 7d8545e, the current payload is one measured observation: 1,110 stores and 5,551 bytes. The corrected independent projection contains 1,702 changed bytes. Byte-only encoding would require 8,511 bytes and fail the 8,192-byte page limit by 319 bytes. Greedy pairing yields 690 pairs plus 322 singles, a projected 5,751-byte payload with 2,441 bytes spare. The current measured reset range is 14,131–16,609 active cycles; instruction-cycle arithmetic projects a maximum of 17,303, leaving 9,697 cycles to the 27,000-cycle engineering maximum. The loader currently ends at $C3C7 against the $C800 guard, leaving 1,081 assembled bytes for the bounded synthesizer change. Current release capacity is resident 8,188/8,192 bytes, presentation 1,276/1,280, enemy 4,090/4,096, cold presentation 7,636/10,874, and GMC source spare 3,965 bytes. These are current single measurements except the explicitly identified payload and cycle projections; assignment acceptance requires fresh assembled values and complete-interval measurement.

Rejected alternatives are an 8,511-byte byte-only payload because it exceeds page $20; changing draw_perimeter_box because it would corrupt the correct incremental geometry; compressing the maze renderer because it changes approved output; and suppressing the reset publication because it leaves retained Green progress on death.
