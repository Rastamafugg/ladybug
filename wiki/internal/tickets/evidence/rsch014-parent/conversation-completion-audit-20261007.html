Evidence-based critique

  1. Incorrect integration reporting. BUG-087 root commit 163d0be is already integrated. Its production src/scripts tree matches executor commit 7845dfa. The canonical ticket already recorded integration on 2026-10-06, so later claims that candidate source integration remains were stale.
  2. Invalid inference from endpoints. The reversal search and cadence audit began with identical captured state. The cadence run observed seven cumulative releases and a death reset at timer entry 1950; both runs ended with zero active/released enemies. The fixture run examined 2400 callbacks versus 2306, and its FRAMES and FB_SIM_SEQ endpoints are both exactly 94 greater. This does not prove identical trajectories, but directly invalidates the asserted evidence of differing paths. The RNG source description is real; the proposed RNG investigation was not justified by this comparison.
  3. Testing was allowed to become the main project. The BUG-087 adapter has 2635 nonblank lines; the cleanup evidence tree has 828 files at review time. Size alone does not prove redundancy. However, repeated stale-key, breakpoint-order, mapping-alias, actor-equality and raw-frame-delta mistakes demonstrate avoidable observer churn. Many complete natural setup runs were repeated while chasing a rare NPC route that had no guarantee of appearing before death/reset.
  4. Rare-path setup was overconstrained. The approved reversal handler expects an already-prepared valid fixture and performs no writes during measurement. The original product requirement does not require a lucky natural RNG route to a particular cell. Use an existing coherent fixture harness to prepare two legal actors, then verify the real chooser, real callbacks and published pixels with gate 0 unchanged and no measurement writes. If the current no-write contract also forbids setup, obtain one explicit setup-method amendment; do not silently change acceptance.
  5. Scope and lifecycle were conflated. Functional B2/C3 completion was repeatedly counted as incomplete cleanup because historical parent timing gates remain open. Many other tickets were already executed by Luna agents despite reports emphasizing that a broader wave had not started. Current badges and several metadata lines also disagreed. Maintain one current requirement matrix; keep older decisions in the history.
  6. Useful evidence was left unfinished. All six FEAT-005 candidate windows already exist on the same ROM/helper/build identity: 36 samples, maximum 26574 versus 27000, margin 426. A separate remapping trace has 999 pairs and zero mismatches. The candidate remains isolated, but this is enough to finalize a concrete approval brief rather than restart performance diagnosis. Its earlier corruption is prototype-specific, not a proved current-root defect.
  7. Estimates lacked a work model. The previous 4–8 working-day claim was not derived from a critical path or established BUG-058 solution. Replace it with explicit remaining deliverables and confidence. The large gameplay performance gap remains research risk, so no reliable total completion date is available.
