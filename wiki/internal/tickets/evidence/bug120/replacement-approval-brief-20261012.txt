Movement and collision contract
At each input, admit a requested low-nibble edge only when it is open; if that request executes an actual diagonal snap, also require the complete opaque swept sprite path to be clear. For a rejected direct request during a partial cell, project the next center along the existing axis. Continue along the old-axis path only if the full opaque sprite has a clear straight approach to the projected center and the requested centered cardinal exit is open there. Then turn at the center. This lookahead does not execute a diagonal snap, so do not require or consult a hypothetical future six-pixel hazard. Otherwise hold the exact position, step, direction, and snap state while retaining the attempted facing. A direct unsafe snap is never admitted merely because the graph edge is open. Do not use a universal four-pixel window, restrict facing, or prune a whole edge when only a particular swept turn is unsafe. Preserve neutral input, reversal, ordinary aligned movement, and all legal six-pixel corrections.

The bounded geometry candidate is the prior static design, requalified on current inputs: move generated cursor and node sprite origins down one scanline (+160 framebuffer bytes) together; keep logical cells, action coordinates, walls, and text destinations fixed; account for the sprite's one-cell-right overhang in the reciprocal edge graph; retain the 576-byte table with low-nibble cardinal exits and four upper-nibble unordered-pair hazard flags for NE/ES/SW/WN. The flags represent all facings and animation frames across actual six-pixel diagonal snap sweeps only. They do not gate centered lookahead turns, whose admission requires a clear straight approach and an open centered exit. Preserve zero flags at blocked and perimeter/top/right-anchor cells. Preserve the name callback's A edge/passability result and full table byte in B; restore PAR5 to $34 after cold mapping on every return.

Upcoming-center probes must not mutate live PLAYER_CELL, PLAYER_FB, PRES_NAME_ROW/COL, step, or snap state. Seed existing TEST_X/Y scratch with the current or projected cell and let the mirrored stage/ranking name callback classify those explicit coordinates. Both callback copies must return A passability plus the original full table byte in B and restore PAR5. The ranking copy currently uses B as a rotate count and consumes its saved mask with `ANDA ,S+`; revise that bounded selector so it restores the full mask to B after producing A. Verify the two copies' contracts and emitted code agree. The exact callback-byte cost and branch encodings remain unmeasured.
