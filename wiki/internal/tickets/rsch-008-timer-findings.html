Confirmed source defect

The generated timer record is a four-byte pair: destination address followed by a 16-bit pointer to raw green tile bytes. scripts/build_presentation.py:2044-2053 appends framebuffer_destination(cell) and name_entry_timer_tiles_offset + green_index * TILE_BYTES; the current generated include has 92 records (368 bytes), with the first record 20 50 2C 90 (destination $2050, raw tile pointer $2C90).

The active complete shared-text helper is selected by src/demo_runtime.s:2-8 and includes src/shared_text_stage.inc when HIGHSCORE_PHASE_HELPER is set. In src/shared_text_stage.inc:148-161, the consumer loads the destination into Y, then executes LDB 3,X, and calls PRES_MODULE_DRAW_TILE. The same sequence exists in src/shared_text_ranking.inc:148-161 and the resident-side path src/presentation_runtime.s:2606-2619. The called draw routine contract at src/presentation_runtime.s:2289-2323 interprets B as a one-byte atlas tile ID, computes B*32 + PRESENTATION_TILE_ATLAS_OFFSET, and blits that atlas tile. Therefore the low byte of a raw tile-data pointer is used as an atlas ID. This is a confirmed source-level cause for unrelated art in timer squares; runtime reproduction remains unclaimed.

There is a second, independent defect in the page-$23 helper copy at src/shared_text_stage.inc:154-161 and src/shared_text_ranking.inc:154-161: after the correct LDB 3,X, LDD #highscore_after_tile overwrites B before the jump. The helper thus passes the low byte of its continuation address as the tile ID, regardless of the record contents. src/demo_runtime.s:156-170 duplicates this exact sequence in the helper source. This explains deterministic unrelated tile selection even if the record encoding were otherwise accepted.

Remapping and stale-ID assessment

Tile remapping is not the primary defect. scripts/build_presentation.py:1930-1953 remaps timer base IDs, then deliberately clears timer_green_tile_ids after the green variants have been deduplicated into timer_green_tiles. The later table emission at 2044-2053 stores raw green-surface pointers, not IDs. The current source therefore has a producer/consumer format mismatch before any stale-ID or atlas remap question can arise. The timer base IDs are not consumed by the timer record path.

Rejected explanation: a simple stale generated timer include is insufficient. The authored generator and all three current timer consumers agree on the four-byte pointer-shaped record only accidentally; the consumer explicitly treats byte 3 as an atlas ID. Rejected explanation: green palette generation alone. replace_packed_colour(... WHITE, GREEN) at scripts/build_presentation.py:1780-1786 produces a valid native green surface, but that surface is never selected by the draw consumer when it receives the pointer byte as an ID.

Repair direction and smallest future runtime check

Repair direction: choose one ABI and enforce it at generation and consumption. The smallest coherent direction is for the timer consumer to use the record's 16-bit source pointer as Y (with destination preserved separately) and call a raw native-tile blitter, or alternatively emit/remap a one-byte atlas ID and keep the existing draw_tile_id ABI. The helper continuation address must be installed without clobbering the tile argument, for example by preserving/reloading B after writing the callback pointer. Parent review must select the direction before implementation.

Smallest future runtime check: in the enter-high-score phase, force the first timer record on both framebuffer owners, stop immediately before the draw call, and verify that the selected source bytes equal the generated first green-tile bytes and that the destination is $2050. Then execute one draw and compare the destination's 32 bytes against a software native blit of that same source. A timeout means the probe boundary or callback path was not reached, not that the timer is slow. Residual uncertainty: this source report cannot establish live mappings, callback register preservation in the loaded artifact, or framebuffer publication behavior.

Conclusion

The unrelated timer art has a confirmed source defect: raw green-tile pointers are passed through an atlas-tile-ID ABI, and the helper callback setup then overwrites B again. Stale-ID remapping and framebuffer-owner history remain secondary runtime checks after the ABI is repaired.
