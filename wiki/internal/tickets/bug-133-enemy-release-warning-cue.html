Root Cause & Arcade Reference

  • Current CoCo 3 (src/audio_runtime.s:591–598): Cue 5 (enemy-release, 84 ticks / 1.4 s rising warning siren) is enqueued when ENEMY_RELEASED increments, so it starts after the enemy has already been released.
  • 1981 Arcade Z80 ROM ($3A08–$3A48): On the top-left perimeter approach ($6060 == 0, $6061 == 1, 11 boxes before release at $6061 == 12), if any dormant enemy is waiting in the den, bit 5 of $6000 is set to trigger Cue 5 as a pre-release warning.

Approved Scope & Acceptance Criteria

  2. Do not trigger Cue 5 when all 4 enemies are already active (vegetable phase) or during player death.
