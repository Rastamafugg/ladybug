Stop style-1 gate remnants, dot-cell corruption, A/B flicker, and the resulting out-of-bounds stack write.

Approval brief

Objective and motivation

Make both persistent framebuffers converge to the authoritative gate and dot state after either diagonal style, while preventing replay from treating live RENDER_ZONE_Y as a gate style.

Baseline and cause

At revision deea3c9, all 20 style-1 natural gate cases retained 13–20 differing bytes in the gate region; all style-0 cases converged. The 16-byte intent record is: gate ID 9, mode 10, second gate ID 11, second mode 12, live zone Y 13, primary style 14, secondary style 15. Gate-only replay read byte 13 as style, and coalescing cleared byte 13 or 14 instead of the style fields. Values beyond the two-entry dot-offset table could direct writes outside the framebuffer.

Scope

In: style-field addressing and coalescing clears, live zone-field preservation, focused convergence and locality verification, and required wiki/ticket evidence. Out: enemy navigation, gate rules or graphics redesign, framebuffer protocol changes, and unrelated crash hypotheses.

Acceptance criteria

  • Natural and reversed-owner all-gate/style convergence pass 40/40 each.
  • Present/collected dot cases pass 4/4.
  • Primary style reads byte 14; secondary style uses byte 15; byte 13 remains RENDER_ZONE_Y.
  • Safe low-RAM canary remains unchanged for both styles; randomized XRoar soak reaches timeout with no crash markers.
  • GMC boot, enemy-runtime, cache, transition, no-overlap, performance-baseline, compatibility, and HTML-link checks pass.

Discriminating reproduction

Freeze actors, force each gate and diagonal style through the natural GATE_ANIM_ID diagonal-to-final sequence, execute five render entries, and compare both physical gate regions. Before the fix, style 1 failed 20/20. After the fix, natural and reversed-owner runs both pass 40/40. Present/collected diagonal-dot variants pass 4/4.

Implementation

src/main.s now loads pending primary style at offset 14. src/enemy_runtime.s now clears primary style at offset 14 and secondary style at offset 15 during coalescing. No other gameplay or framebuffer protocol behavior changed. Added scripts/verify_bug001_gate_replay.py and retained build/bug-001-gate-style.json.

Verification and completion

QA verdict: accepted. Natural convergence is 40/40; reversed-owner convergence is 40/40; dot variants are 4/4; canary $1D00=5AA5 is unchanged for both styles; randomized XRoar soak reaches the timeout without crash markers. Current build uses 8,190/8,192 resident bytes, 7,144/7,680 asset bytes, and 4,075/4,096 bank-3 bytes. GMC boot, enemy-runtime, cache, transition, no-overlap, performance-baseline, compatibility, and link checks pass. The maximum required gate worklist remains 26,991 cycles against the 27,000-cycle target.
