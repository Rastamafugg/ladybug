BUG-065 — Match instruction multiplier digits to the blue X Draft

2026-10-01 · P2 · Standard · Draft · RSCH-014 Step A

Approval brief

Objective and motivation

Color the multiplier numerals 2, 3 and 5 blue wherever the instruction screen shows them beside the blue X glyph.

Evidence, reproduction and cause

The authored template X2/X3/X5 cells at (1–6,7) are raw character GIDs 147/465/147/449/147/417; those GIDs identify shapes and do not encode blue. The current compiled template maps all six cells to GREY pen 7. Generated X2/X3/X5 replacements map X to BLUE pen 3 but their digits to WHITE pen 6 at both point-row destinations. An in-memory compiled-screen candidate colors all six authored cells and both generated multiplier digits blue; it changes 74 packed frame bytes and edits no TMX. The user specifically said X5 should be blue “in the template TMX file.” It is unresolved whether that means the compiled preview from the TMX or the Tiled editor view itself. Raw GIDs do not encode color and the current screen compiler only accepts chars_raw2bpp; a Tiled-editor-visible requirement needs a separate authored-data/tileset/compiler design. This unresolved acceptance choice keeps the ticket Draft and its assignment non-dispatchable.

Scope

In: the template X2/X3/X5 multiplier legend and generated runtime multiplier replacements in both point rows. Out: 10/100 point-award digits, ordinary point values, heart colors, trigger order and multiplier scoring.

Design and prototype

Candidate if compiled preview is sufficient: use BLUE pen 3 for X2/X3/X5 cells at (1–6,7) and generated digits 2/3/5 at (27,17) and (27,20). Do not recolor ordinary 10/100 point-award digits. If blue must be visible in Tiled itself, rework the design before approval; no TMX or tileset implementation has been chosen.

Scenarios and edge cases

  • Pending user decision: compiled static preview criterion is all six authored X/digit cells at (1–6,7) blue pen 3. If the Tiled editor must show blue, specify an authored representation and prove the compiler consumes it before finalizing acceptance or file ownership.
  • Generated X2/X3/X5 replacements at (27,17) and (27,20) use BLUE pen 3 for both X and numeral on every publication; ordinary 10/100 award text retains its authored color.
  • Static compiler comparison reports only the approved multiplier pixels changed; both authored multiplier destinations and the current movement/color schedule remain unchanged.
  • Existing instruction verifier, current complete build/capacity guards and natural instruction capture pass after FEAT-005/layer integration.
