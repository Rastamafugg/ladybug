Cause and first discriminator

BUG-028 rejects the proposed missing-abort explanation for the observed timeout. The durable control completed natural frame zero and hydration frame one through normal RTS $0A07. On hydration frame two, the primary resumed with 50,917 ms remaining but received no event. At the reserved recovery boundary, an independent observer found XRoar already halted at configured restore_player=$D612, breakpoint ID 26. The seven listed breakpoints exactly matched the requested IDs/addresses, live bytes matched the resident image, and FRONT fault was zero. The confirmed category is primary breakpoint-notification delivery/correlation failure, not frame-return selection, execution slowness, deadline depletion, lifecycle drift, or artifact drift. XRoar source contains a compatible event-drop path: subscriber delivery uses a nonblocking client write-lock attempt and intentionally drops an event when that lock is busy. The protocol’s stateful wait_for_stop path is the bounded repair candidate, but changing the runner to use it requires separate approval.
