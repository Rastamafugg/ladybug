Observed versus expected

Observed: the approved RSCH-007 command completed all isolated cases, then its first full-GMC trap launch failed to reach mapped frame_render_impl=$09D9 within the 60-second runtime deadline. The deterministic monitor rerun reached mapped start_screen=$1A00 with a request other than attract; after adding live presentation-window and attract-request validation, no accepted startup arrived within 60 seconds. Static preparation then proved that the ambient artifacts were not the required complete profile: build/ladybug-presentation-runtime.map records BUG011_DEVELOPMENT_PROFILE=0, COMPLETE_PROFILE=0, and HIGHSCORE_TEST_PROFILE=1, while build/ladybug-gmc-boot.map independently records HIGHSCORE_TEST_PROFILE=1. The runner had interpreted a valid high-score-test request using the complete/release attract contract.

Expected: the runner rejects an incompatible ambient profile before launching XRoar. With an explicitly built complete artifact, one bounded startup path proves authored presentation/enemy source, staged module/ROM, and live bytes before navigating attract, credit, level-start, and gameplay. It then reaches frame_render_impl within 60 seconds and leaves the existing RSCH-007 runtime cases unchanged.

Cause and discriminator

The confirmed primary cause is missing runtime-artifact profile provenance: RSCH-007 consumed the ambient default highscore-test build while its navigation required the complete profile. The discriminating control parses the profile constants independently from the presentation and GMC-bootstrap maps and rejects anything except BUG011_DEVELOPMENT_PROFILE=1, COMPLETE_PROFILE=1, and HIGHSCORE_TEST_PROFILE=0 before XRoar launch. After an explicit complete build, the runtime control follows mapped boot_entry=$C002, presentation_flow_tick=$1900, start_screen=$1A00, and frame_render_impl=$09D9; it records the request and derives its caller from the live S-stack return address and current presentation listing. Any profile disagreement, staged/live byte mismatch, unexpected caller, or missing marker fails at its first boundary.
