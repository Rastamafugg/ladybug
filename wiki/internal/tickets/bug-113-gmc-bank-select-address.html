Approval brief

Objective and motivation

Change the GMC bootstrap bank-select address from the CoCo 3 SCS alias $FF50 to the guide's primary register $FF40. This aligns Ladybug with the documented GMC interface and removes the bank-address mismatch recorded in the MAME 0.220 control. The change targets boot compatibility; it adds no new game behavior and replaces no runtime owner.

Evidence and baseline

At pre-change base commit 541f6f1, the bootstrap source defined GMC_BANK equ $FF50 and had nine STA GMC_BANK sites. The same source enabled GIME Init0 SCS with value %01101100. The paired current HST MAME run and candidate result are recorded below.

The ingested Programming the Game Master Cartridge guide identifies $FF40 as the write-only bank-select register. Existing MAME 0.220 evidence is historical: the then-current image used five literal STA $FF50 operands, failed bank-signature checks, and showed a striped frame; a control changing only those five operands to $FF40 reached a coherent high-score screen within four emulated seconds. Local XRoar evidence accepts the $FF50 alias. The historical control predates the current source and is not current-revision acceptance evidence.

The bank register is write-only, so acceptance must use bank signatures, copy/handoff results, and visible startup output rather than register readback. Changing the address operand is projected to add or remove zero bytes; the build must confirm unchanged module size and capacity.

Options and recommendation

  • Recommended — use $FF40: matches the ingested guide and historical MAME control while retaining the existing loader and SCS-enable path. Residual risk: physical hardware is not available for a direct test, and the audio alias at $FF51 remains a separate compatibility question.

  • Write both addresses or add emulator-specific behavior: rejected for this proposal because it adds unneeded writes or branching and obscures the single documented hardware contract.
