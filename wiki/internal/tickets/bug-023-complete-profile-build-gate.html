Objective and motivation

Make LADYBUG_PROFILE=complete scripts/build.sh run reach XRoar after proving that the generated complete image satisfies the intended profile contract. The default highscore-test path currently runs; the complete path exits during build validation.

Reproduction and observed facts

At source revision 47d54bb, with the pre-existing dirty worktree preserved, run:

wsl -d Ubuntu -- bash -lc 'cd /mnt/e/projects/ladybug && LADYBUG_PROFILE=complete ./scripts/build.sh build'

The build generates the complete maze, presentation, sparse, loader, capacity, and GMC artifacts, then exits with:

FEAT-003 isolation: complete ROM hash 9affb91742503658b20fe63ebd2230b2333efb2e476c978b9531706377ce26b1 != b065057e74b448ea22acbafe5dcb4773f46d338fd9f66c99dd37b68e7fcb05fc

Because scripts/build.sh run calls build first, XRoar is not invoked. A direct bounded XRoar control using the generated ROM initialized CoCo 3, 512 KB RAM, and GMC successfully; this proves the immediate script failure occurs at the build gate, not at XRoar option parsing or emulator initialization. Complete behavioral validity remains unverified at the current hash.

Confirmed cause and remaining question

Confirmed cause: scripts/verify_feat003_profile_isolation.py contains a hard-coded COMPLETE_SHA256 of b065057e... and rejects the current generated complete image before launch.

Remaining question: determine whether the current complete image contains an unintended shared-artifact change that must be isolated, or whether the retained baseline and guard require an evidence-backed update. Updating the constant or removing the guard without a natural complete-profile check is prohibited.

Scope

In: compare current and retained complete artifacts; identify the first source/generated difference; validate complete natural phase progression; reconcile the guard, profile documentation, and ticket evidence; preserve the default profile and CPU selector.

Out: 6309-only optimization, separate ROM products, gameplay redesign, loader/MMU redesign, capacity expansion, and bypassing the profile-isolation check.
