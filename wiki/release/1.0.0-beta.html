Ladybug 1.0.0-beta

Beta release of the 6809 port of Universal's 1981 *Lady Bug* for the Tandy Color Computer 3 with 512 KiB RAM. The game runs natively, without NitrOS-9.

Download

Download coco-ladybug-1.0.0-beta.rom from the release assets. This is the complete adaptive-rendering keyboard build, packaged as a 64 KiB, four-bank GMC cartridge image. SHA256SUMS.txt provides the asset checksum. GitHub's source archives contain the tagged source at commit 11927e3066bda9d35fab5a79ad7d2bfb7558ae28.

Changes since the alpha

  • Standardized screen-map layers, sprite locations, backgrounds and maze borders; cleaned up attract and instruction screens.
  • Updated the menu to Start Game, Options and Credits. Keys 5/6 add credits; arrows and Enter navigate menus. Starting requires a credit. Gameplay controls remain configurable and also control the ladybug during name entry.
  • Added consistent part formatting: two digits with a leading zero for single-digit parts, expanding to three digits when needed. Corrected score, multiplier, vegetable-value and rank displays across screens.
  • Expanded life indicators to a four-by-three grid for up to twelve lives. Life markers fill left-to-right, bottom-to-top, and are removed in reverse order. Every replacement-life ladybug now exits directly to the right.
  • Corrected the starting collectible colour, logo animation timing, later-level enemy succession and enemy rate progression. Bounded catch-up work prevents extended movement bursts after stalls. Reduced unnecessary pickup rendering and repaired presentation transitions.
  • Corrected high-score entry colours, score authority, last-part vegetable/value, placement labels and symbol selection; removed the stray score field.

Run in XRoar

xroar -machine coco3 -machine-cpu 6809 -ram 512 -cart-type gmc -cart-rom coco-ladybug-1.0.0-beta.rom -cart-autorun -tv-input rgb -joy-right "" -joy-left ""

Press 5 or 6 to add a credit, release Enter if already held, then press Enter to start. Use the options menu to configure gameplay controls.

Build from the tagged source

git clone --branch 1.0.0-beta https://github.com/Rastamafugg/ladybug.git
cd ladybug
LADYBUG_PROFILE=complete LADYBUG_INPUT=keyboard LADYBUG_CPU=6809 LADYBUG_ADAPTIVE=1 bash scripts/build.sh build

Requires Python 3 and LWTOOLS (lwasm) in a Linux shell, including Ubuntu under WSL. The output is build/ladybug.rom.

Validation and remaining beta limits

The completed source passes the full build, sprite/presentation decoding, loader/layout/capacity guards and source-documentation audit. The attached ROM is byte-for-byte identical to the completed build manually tested for this beta.

  • Rendering stalls and gameplay slowdown can still occur. The separate 27,000-cycle performance targets remain open; proposed PERF-009 and PERF-010 optimizations are not included in this release.
  • Physical CoCo 3 hardware qualification remains incomplete. This release's retained runtime evidence is from XRoar.
  • Gameplay in MAME remains unverified; the existing GMC bank-selection compatibility issue is unresolved.
