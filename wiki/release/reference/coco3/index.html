CoCo 3 Hardware

Bare-metal reference for the Tandy Color Computer 3 — GIME, MMU, memory map, cartridge, input, sound, timing.

Pages

  • GIME / ACVC

    Register catalog, palette, MMU, IRQ/FIRQ, timer, legacy SAM bits.

  • Memory map

    Virtual / physical, PAR sets, ROM/RAM modes, dedicated-address landing zone.

  • Cartridge connector

    40-pin pinout and the CART → PIA2 CB1 → FIRQ auto-start handshake.

  • Input

    Keyboard matrix, joystick fire buttons, joystick X/Y A/D loop.

  • Sound

    6-bit DAC, 1-bit PB1 square wave, selector switch.

  • Timing

    MPU clock, periodic interrupts (Vbord, Hbord, Timer), frame budget.

Primary sources: Tepolt, Assembly Language Programming for the Color Computer and … for the CoCo3 (Spectral Associates); Tandy Color Computer 3 Service Manual.
