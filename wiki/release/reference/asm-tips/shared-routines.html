Assembly tips · reuse

Shared routines and lookup data release

Store repeated facts once and share code where its dispatch cost is worthwhile.

Separate a reusable shape from its parameters

When many objects follow the same operation with different data, store the variation in descriptors and call one routine. This can reduce duplicated code and make shared rules easier to correct. A descriptor should contain only what the common routine needs, with a clear type or length when records can have different shapes.

Ladybug's gameplay_dispatch distinguishes native tiles from text descriptors, and its presentation dispatcher distinguishes graphics from text. Both route common cases to existing drawing routines rather than carrying a separate copy of the drawing loop for each screen item. See src/shared_text_runtime.inc.

Reuse masks; vary colour through a table

A compact one-bit glyph mask says which pixels are present. A colour lookup table expands mask bits into native pixel values, so the same mask can be drawn with different colours. This avoids keeping one fully coloured copy of every glyph for each palette choice. 

; Select a colour row, then use its entries to expand mask bits.
        lda     HUD_COLOR
        ldb     #32
        mul
        leau    colour_lut,pcr
        leau    d,u
        lda     ,y+
        anda    #$F0
        lsra
        lsra
        lsra
        ldd     a,u

This pattern is used by shared_mask in Ladybug. The direct benefit is shared data and one renderer. Each draw still pays for colour selection, lookup, and dispatch; measure the complete workload before deciding whether a specialized path is warranted.

Use compact typed descriptors

A type field can select a common interpretation for the remaining descriptor fields. Keep the type test and the data layout together, and document index bounds. This gives a small interface between authored content and assembly code, but adds a lookup and branch before the operation.

  • Use shared code when many callers perform the same work.
  • Use separate code when the operations have different invariants or a measured hot path needs specialization.
  • Do not turn values with different units or ownership into one descriptor merely to reduce the number of labels.

The related indexed-addressing guide covers fixed-stride records. For the instruction-level operations, see MUL, LDA, and LEAU.
