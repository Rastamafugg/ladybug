Reference

Hardware and assembly reference for the Tandy Color Computer 3 and the Motorola 6809E CPU. Used by the Ladybug web app as inline contextual help.

Sections

  • 6809 instruction set

    Every Motorola 6809 mnemonic, one page each. Syntax, addressing modes, condition codes, cycles, examples.

  • CoCo 3 hardware

    Memory map (bare-metal, no NitrOS-9), GIME registers and modes, MMU/PARs, palette, IRQ, sound, input, timing.

  • Assembly programming tips

    Direct-page conventions, register allocation, addressing patterns, timing-critical code on the CoCo 3.

Primary sources: Motorola MC6809E HMOS 8-Bit Microprocessor data sheet; Tepolt, Assembly Language Programming for the Color Computer and … for the CoCo3 (Spectral Associates); Tandy Color Computer 3 Service Manual.
