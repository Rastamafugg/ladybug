6809 · Shift / Rotate

ROL / ROLA / ROLB — Rotate Left Through Carry

new C ← b7; b6→b7, …, b0→b1; old C → b0

ROL  <operand>
ROLA
ROLB

Description

9-bit rotation left through C: bit 7 of the operand goes into C, the previous C goes into bit 0. Used to chain shifts across bytes — e.g. 16-bit left shift in D is ASLB then ROLA.
