CMPA — Compare A with Memory

A − (M), result discarded; flags set

CMPA  <operand>

Description

Performs A − (M) but discards the result, leaving A unchanged; only the flags are updated. Follow with signed branches (BGE/BLT/...) or unsigned branches (BHS/BLO/...) to act on the comparison.

Condition codes

EFHINZVC
––U–↕↕↕↕
  • Z — equal.
  • C — set if A < (M) unsigned.
  • N XOR V — set if A < (M) signed.
