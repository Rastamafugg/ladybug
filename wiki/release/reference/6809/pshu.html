PSHU — Push Registers onto U Stack

push the selected register set onto U

PSHU  <register list>

Description

Identical to PSHS but uses the user (U) stack pointer. A post-byte selects any subset of PC, S, Y, X, DP, B, A, CC (note S replaces U in the list when pushing onto U). The mirror pull is PULU.

The U stack is handy for a private data stack, parameter passing, or a coroutine context separate from the S call stack.
