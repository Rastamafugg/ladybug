6809 · Arithmetic

DEC / DECA / DECB — Decrement

operand ← operand − 1

DEC  <operand>
DECA
DECB

Description

Subtracts 1 from the operand in place. Sets Z when the result is zero — the common loop-counter pattern is DECB followed by BNE loop. C is not affected by DEC/DECA/DECB; use SUBA/SUBB if you need to capture the borrow.

Condition codes

EFHINZVC
––––↕↕↕–
  • V — set if the operand was $80 (signed overflow).
  • C — unaffected.
