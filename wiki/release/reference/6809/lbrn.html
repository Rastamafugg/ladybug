6809 · Branch (long)

LBRN — Long Branch Never

no branch (consumes a 16-bit offset)

LBRN  <label>

Description

Never branches; execution falls through. The long counterpart to BRN, it is useful as a four-byte no-op placeholder that can be patched into any long-branch opcode, or to consume timing.
