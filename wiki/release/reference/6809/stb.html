6809 · Load / Store

STB — Store Accumulator B

M ← B

STB  <operand>

Description

Stores accumulator B into the addressed memory location. N and Z reflect the stored value; V is cleared.

Condition codes

EFHINZVC
––––↕↕0–

Addressing modes

ModeSyntaxOpcode~#
Direct STB <nD742
Indexed STB n,R E74+2+
ExtendedSTB n F753

Examples

        STB   <count
        STB   ,X+
