6809 · programming model

Condition Codes

The 8 bits of the CC register: E F H I N Z V C. Set and cleared by arithmetic, logical, compare, and stack/interrupt instructions; masked with ORCC / ANDCC.

Bit semantics

BitNameMeaning
7EEntire-state stacked. Set when an IRQ/SWI/NMI pushed all registers (so RTI pops them all); clear when only PC+CC were pushed (FIRQ path).
6FFIRQ mask. When set, FIRQ is ignored.
5HHalf-carry. Set on a carry from bit 3 of an 8-bit add (used by DAA).
4IIRQ mask. When set, IRQ is ignored.
3NNegative. Mirror of the high bit of the most recent result (bit 7 for 8-bit ops, bit 15 for 16-bit ops).
2ZZero. Set when the most recent result was zero.
1VSigned overflow. Set when an add or subtract produced a result that overflows the signed range.
0CCarry / borrow. Carry out of bit 7/15 on add; borrow on subtract; shift/rotate bit-out.

Common CC effects

  • Load 8-bit (LDA/LDB): N from bit 7, Z from zero-ness, V ← 0. C unaffected.
  • Load 16-bit (LDD/LDX/LDY/LDU/LDS): same but N from bit 15.
  • Store (STA/STB/STD/STX/...): CC mirrors the value being stored — N from high bit, Z from zero, V ← 0.
  • Add (ADD/ADC): H NZ VC all updated (8-bit forms include H; 16-bit forms omit it).
  • Subtract / compare (SUB/SBC/CMP): NZ VC. C is the borrow.
  • Logical (AND/OR/EOR/COM/BIT): NZ V0. COM additionally sets C ← 1.
  • Shift / rotate: shift-out goes into C. LSR always clears N.
  • CLR / CLRA / CLRB: N0 Z1 V0 C0.
  • LEA: only LEAX and LEAY affect Z. LEAS and LEAU leave CC untouched.
  • TFR / EXG / PSH / PUL: do not affect CC themselves, but PULS/PULU with CC in the postbyte restore CC from the stack.

Branch predicates

Conditional branches test CC. Short forms (8-bit signed offset, ±127); long forms (page-2 prefix, 16-bit offset, ±32 K).

MnemonicCondition
BRA / BRNalways / never
BEQ / BNEZ = 1 / Z = 0
BCC / BHSC = 0 (carry clear / unsigned higher-or-same)
BCS / BLOC = 1 (carry set / unsigned lower)
BHI / BLSunsigned higher / lower-or-same
BPL / BMIN = 0 / N = 1
BVC / BVSV = 0 / V = 1
BGE / BLTsigned ≥ / <
BGT / BLEsigned > / ≤

CC manipulation

  • ORCC #imm — bit-wise OR an immediate into CC. Used to set mask bits — e.g. ORCC #$50 to mask both IRQ and FIRQ during a critical section.
  • ANDCC #imm — bit-wise AND. Used to clear mask bits — e.g. ANDCC #$EF to unmask IRQ.
  • CWAI #imm — clear CC bits per immediate, then wait for interrupt.

Reference: Motorola MC6809E HMOS 8-Bit Microprocessor data sheet; Tepolt, Assembly Language Programming for the Color Computer ch. 3, App. B.
