6809 · Load / Store

LDA — Load Accumulator A

A ← (M)

LDA  <operand>

Description

Loads the contents of the addressed memory location into the 8-bit accumulator A. The N and Z flags are set from the loaded value; V is cleared; H, I, F, C are unaffected.

Pair with LDB when both halves of D are needed independently, or use LDD to load both at once in a single 16-bit operation.

Condition codes

EFHINZVC
––––↕↕0–
  • N — set if bit 7 of the loaded value is 1.
  • Z — set if the loaded value is zero.
  • V — always cleared.
  • H, I, F, C — unaffected.

Addressing modes

ModeSyntaxOpcode~#
Immediate LDA #n 8622
Direct LDA <n9642
Indexed LDA n,R A64+2+
Extended LDA n B653

~ = clock cycles. # = instruction bytes. Indexed mode adds 0–4 cycles and 0–2 bytes depending on the post-byte form. See addressing modes for the full post-byte breakdown.

Examples

        LDA   #$20         * immediate: A <- $20
        LDA   <palette     * direct page: A <- (DP:palette)
        LDA   ,X+          * post-increment indexed: A <- (X), X = X+1
        LDA   2,Y          * 5-bit offset indexed
        LDA   score        * extended: A <- ($nnnn)
        LDA   [vector]     * extended indirect via $nnnn

Use the direct-page form whenever the variable lives in the configured DP region — it saves one byte and one cycle versus extended on every access. See DP conventions.
