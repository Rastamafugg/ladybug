TST / TSTA / TSTB — Test

set N and Z from operand; V cleared; operand unchanged

TST  <operand>
TSTA
TSTB

Description

Sets N and Z based on the operand's value, clears V, leaves C unaffected. Equivalent to CMP r,#0 but shorter for the inherent forms (TSTA/TSTB are 2 cycles / 1 byte).

Note: TST on a memory operand performs a read–modify–write cycle (writes the original value back). This matters when reading from memory-mapped registers with side-effect-on-write — use LDA + test instead.
