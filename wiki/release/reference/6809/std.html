6809 · Load / Store

STD — Store Accumulator D

M:M+1 ← D

STD  <operand>

Description

Stores the 16-bit concatenated accumulator D (A:B) into M:M+1. N and Z reflect the 16-bit stored value; V is cleared.

Condition codes

EFHINZVC
––––↕↕0–

Addressing modes

ModeSyntaxOpcode~#
Direct STD <nDD52
Indexed STD n,R ED5+2+
ExtendedSTD n FD63

Examples

        STD   <score       * 16-bit store
        STD   ,X++         * (X:X+1) <- D, X = X+2
