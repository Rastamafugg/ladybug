6809 · Load / Store

LDU — Load User Stack Pointer

U ← (M:M+1)

LDU  <operand>

Description

Loads a 16-bit value into the user stack pointer U. N and Z reflect the loaded value; V is cleared. U is a general-purpose 16-bit pointer when not used as a stack.

Condition codes

EFHINZVC
––––↕↕0–

Addressing modes

ModeSyntaxOpcode~#
ImmediateLDU #nn CE33
Direct LDU <nDE52
Indexed LDU n,R EE5+2+
Extended LDU n FE63

Examples

        LDU   #buffer      * U <- buffer address
        LDU   ,X++         * U <- (X), X = X+2
