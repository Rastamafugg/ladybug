SEX — Sign Extend B into A

A ← (bit 7 of B) repeated; D = sign-extended B

SEX

Description

Sign-extends B into A: if bit 7 of B is set, A is set to $FF, otherwise A is cleared to $00. After SEX, D holds the signed 16-bit equivalent of the original 8-bit B.

Common before ADDD, SUBD, or 16-bit indexed offsets when the value started as a signed byte.
