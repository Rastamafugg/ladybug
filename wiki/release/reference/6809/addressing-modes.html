Addressing Modes

How operands are encoded and resolved on the 6809.

Overview

Every 6809 instruction that takes a memory operand selects one of six addressing modes. The mode is determined by the opcode column (or, for indexed mode, by a post-byte that immediately follows the opcode and encodes the index register, offset form, and indirection flag).

Modes

Inherent

No operand; the opcode itself implies its arguments. One byte. 

        CLRA            * clear A
        ABX             * X = X + B (unsigned)
        RTS             * return from subroutine

Immediate

The operand is the byte(s) that follow the opcode. 8-bit immediate for byte ops, 16-bit immediate for word ops. 

        LDA   #$20      * A <- $20
        LDX   #$1C00    * X <- $1C00 (16-bit immediate)
        ANDCC #$AF      * mask CC bits

Direct page

An 8-bit operand is concatenated with the DP register to form the 16-bit effective address. Two bytes, four cycles. Used for hot variables; set DP once and treat the corresponding 256-byte page as your "zero page". 

        LDA   <score    * effective = DP:score
        STA   <$05      * effective = DP:$05

The < prefix forces the assembler to emit direct-mode encoding even when the address could fit a 5-bit indexed form. See DP conventions.

Extended

A 16-bit absolute operand. Three bytes (opcode + addr-hi + addr-lo). Use when the target lives outside the direct page. 

        LDA   $1C00     * extended
        STA   gfx_base  * extended via symbol

Extended indirect

The 16-bit operand points to a memory location holding the actual effective address. Useful for vector tables. 

        JMP   [vector]  * EA = (vector)

Indexed

The opcode is followed by a one-byte post-byte that encodes: which index register (X, Y, U, or S), the offset form, optional auto-inc/dec, and an optional indirection bit.

R is any of X, Y, U, S. The PC-relative forms (PCR) make code position-independent.

Any indexed form (except ,R+ and ,-R) can be made indirect by wrapping the operand in brackets: LDA [n,X] means EA = (X + n). Adds one extra cycle.

Relative

Used only by branch instructions. The operand is a signed offset added to PC. Short branches use an 8-bit offset (range −128…+127); long branches use a 16-bit offset and an extra prefix byte. 

        BNE   loop      * 8-bit signed offset
        LBRA  far_label * 16-bit signed offset

Reference: Motorola MC6809E HMOS 8-Bit Microprocessor data sheet, §3 (Addressing Modes); Tepolt, Assembly Language Programming for the Color Computer.
