6809 · Load / Store

LDD — Load Accumulator D

D ← (M:M+1)

LDD  <operand>

Description

Loads a 16-bit value from M:M+1 into the concatenated accumulator D (A is high byte, B is low byte). N and Z are set from the 16-bit result; V is cleared.

A single LDD is one byte and one cycle cheaper than the equivalent LDA + LDB pair on every mode but immediate.

Condition codes

EFHINZVC
––––↕↕0–
  • N — set if bit 15 of the loaded value is 1.
  • Z — set if the loaded 16-bit value is zero.
  • V — always cleared.

Addressing modes

ModeSyntaxOpcode~#
Immediate LDD #nn CC33
Direct LDD <nDC52
Indexed LDD n,R EC5+2+
Extended LDD n FC63

Examples

        LDD   #$1000       * A=$10, B=$00
        LDD   <score       * 16-bit DP load
        LDD   ,X++         * D <- (X), then X = X+2
        LDD   ptr          * extended
