6809 · Shift / Rotate

ASL / ASLA / ASLB — Arithmetic Shift Left

C ← b7 ← … ← b0 ← 0 (= multiply by 2)

ASL  <operand>
ASLA
ASLB

Description

Shifts the operand left one bit. Bit 7 is shifted into C; a 0 is shifted into bit 0. Equivalent to an unsigned multiply by 2.

Aliases: LSL, LSLA, LSLB assemble to the same opcodes (08/48/58/68/78) — they are the same operation; only the mnemonic differs. Flag semantics are identical for both names.

Condition codes

EFHINZVC
––U–↕↕↕↕
  • C — old bit 7.
  • V — set if the sign bit changed (b7 XOR b6 of the input).
  • H — undefined.
