6809 · Register transfer

TFR — Transfer Register

R1 → R2

TFR  R1,R2

Description

Copies the contents of one register into another. A post-byte names the source and destination via 4-bit codes. Both registers must be the same size: 16-bit (D, X, Y, U, S, PC) or 8-bit (A, B, CC, DP). Mixing sizes is undefined.

Unlike EXG, the source is left unchanged. TFR is the standard way to copy a pointer (e.g. TFR X,Y) or set a stack pointer from another register.

Condition codes

EFHINZVC
––––––––
  • Flags are unchanged unless CC is the destination, in which case it takes the transferred value.

Examples

        TFR   X,Y           * copy pointer X into Y
        TFR   A,DP          * set direct page from A
