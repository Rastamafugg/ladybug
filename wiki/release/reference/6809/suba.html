6809 · Arithmetic

SUBA — Subtract from A

A ← A − (M)

SUBA  <operand>

Description

Subtracts the 8-bit operand from A and stores the result in A. C is set on borrow (i.e. when the unsigned subtraction underflows).

Condition codes

EFHINZVC
