CMPB — Compare B with Memory

B − (M), result discarded; flags set

CMPB  <operand>

Description

Like CMPA, but compares B. B is unchanged.

Condition codes

EFHINZVC
––U–↕↕↕↕

Addressing modes

ModeSyntaxOpcode~#
ImmediateCMPB #n C122
Direct CMPB <nD142
Indexed CMPB n,R E14+2+
Extended CMPB n F153

Examples

        CMPB   #16
        BHS    too_big     * unsigned B >= 16
