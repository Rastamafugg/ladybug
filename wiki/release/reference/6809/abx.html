6809 · Arithmetic

ABX — Add B to X (Unsigned)

X ← X + B (B zero-extended to 16 bits)

ABX

Description

Adds B (treated as an unsigned 8-bit value, zero-extended to 16 bits) to X. No flags are affected. Useful for table indexing where the offset is in B.

LEAX B,X does the same thing in 4+ cycles with an indexed post-byte; ABX is 3 cycles and 1 byte — the smaller, faster form for this common case.

Condition codes

EFHINZVC
