6809 · Arithmetic

ADDB — Add to Accumulator B

B ← B + (M)

ADDB  <operand>

Description

Adds the 8-bit memory operand to B and stores the result in B. Updates H, N, Z, V, and C.

Condition codes

EFHINZVC
