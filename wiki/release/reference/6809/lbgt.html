6809 · Branch (long)

LBGT — Long Branch if Greater Than (signed)

if Z = 0 AND (N XOR V) = 0: PC ← PC + signed 16-bit offset

LBGT  <label>

Description

Long-form of BGT: signed greater-than after a compare (r > m), reaching anywhere in the 64K address space. Taken branches cost one extra cycle.

Condition codes

EFHINZVC
