6809 · Load / Store

STY — Store Index Register Y

M:M+1 ← Y

STY  <operand>

Description

Stores index register Y into M:M+1. Uses the $10 page-2 prefix. N and Z reflect the 16-bit stored value; V is cleared.

Condition codes

EFHINZVC
––––↕↕0–
