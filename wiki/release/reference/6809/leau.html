LEAU — Load Effective Address into U

U ← EA

LEAU  n,R

Description

Loads the indexed effective address into U. No flags are affected. Symmetric with LEAS for managing a user stack frame.

Condition codes

EFHINZVC
––––––––

Addressing modes

ModeSyntaxOpcode~#
IndexedLEAU n,R334+2+

Examples

        LEAU   4,U         * adjust U up by 4
        LEAU   table,PCR   * PC-relative: U <- table address
