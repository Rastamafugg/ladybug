Branch — short (8-bit offset)

MnemonicCondition
BRA (soon)always
BRN (soon)never (useful as a placeholder)
BEQ / BNE (soon)Z = 1 / Z = 0
BHI / BLS (soon)unsigned higher / lower-or-same
BCC / BHS (soon)C = 0 (carry clear / unsigned higher-or-same)
BCS / BLO (soon)C = 1 (carry set / unsigned lower)
BPL / BMI (soon)N = 0 / N = 1
BVC / BVS (soon)V = 0 / V = 1
BGE / BLT (soon)signed ≥ / <
BGT / BLE (soon)signed > / ≤
BSR (soon)branch to subroutine

Branch — long (16-bit offset)

Each short branch above has a long-form equivalent prefixed with L (LBRA, LBEQ, LBSR, …). Long branches add a prefix byte and can reach anywhere in the 64K address space.
