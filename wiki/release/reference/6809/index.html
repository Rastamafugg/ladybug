Branch — short (8-bit offset)

MnemonicCondition
BRAalways
BRNnever (useful as a placeholder)
BEQ / BNEZ = 1 / Z = 0
BHI / BLSunsigned higher / lower-or-same
BCC / BHSC = 0 (carry clear / unsigned higher-or-same)
BCS / BLOC = 1 (carry set / unsigned lower)
BPL / BMIN = 0 / N = 1
BVC / BVSV = 0 / V = 1
BGE / BLTsigned ≥ / <
BGT / BLEsigned > / ≤
BSRbranch to subroutine

Branch — long (16-bit offset)

Each short branch above has a long-form equivalent prefixed with L. Long branches use a 16-bit signed offset (and, except LBRA/LBSR, a $10 page prefix) so they can reach anywhere in the 64K address space.

MnemonicCondition
LBRAalways
LBRNnever
LBEQ / LBNEZ = 1 / Z = 0
LBHI / LBLSunsigned higher / lower-or-same
LBCC / LBHSC = 0 (carry clear / unsigned higher-or-same)
LBCS / LBLOC = 1 (carry set / unsigned lower)
LBPL / LBMIN = 0 / N = 1
LBVC / LBVSV = 0 / V = 1
LBGE / LBLTsigned ≥ / <
LBGT / LBLEsigned > / ≤
LBSRlong branch to subroutine
