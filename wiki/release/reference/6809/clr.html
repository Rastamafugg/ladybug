CLR / CLRA / CLRB — Clear

operand ← 0; flags set to fixed values

CLR  <operand>
CLRA
CLRB

Description

Sets the operand to zero. Flags are forced: N=0, Z=1, V=0, C=0. Convenient for clearing carry as a side effect of clearing a register.

Note: CLR on a memory operand is a read–modify–write — the bus performs a read of the original value before writing 0. Avoid on memory-mapped registers that latch on read.
