CMPU — Compare U with Memory

U − (M:M+1); flags set, U unchanged

CMPU  <operand>

Description

16-bit compare of U. Uses the $11 page-3 prefix.

Condition codes

EFHINZVC
––––↕↕↕↕

Addressing modes

ModeSyntaxOpcode~#
ImmediateCMPU #nn 118354
Direct CMPU <n119373
Indexed CMPU n,R 11A37+3+
Extended CMPU n 11B384

Examples

        CMPU   #buf_end
        BHS    full

See also

CMPS CMPX CMPY LDU LEAU

Tepolt; Motorola MC6809E data sheet. Note: Tepolt Appendix B prints the CMPU opcodes as 118C/9C/AC/BC, which are actually the CMPS opcodes. The correct CMPU opcodes are 1183/1193/11A3/11B3 per the Motorola MC6809E data sheet — used above.
