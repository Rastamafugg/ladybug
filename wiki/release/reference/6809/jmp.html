6809 · Jump / Subroutine / Interrupt

JMP — Jump

PC ← EA

JMP  <operand>

Description

Loads the effective address into PC — an unconditional jump to an absolute (or indexed/computed) address. Unlike BRA/LBRA it is not PC-relative, so the target is fixed regardless of where the code is placed.

Indexed mode makes JMP a powerful dispatcher: JMP [table,X] jumps through a 16-bit vector table entry.

EFHINZVC

Examples

        JMP   restart            * absolute jump
        JMP   [state_vec,X]      * dispatch through vector table
