LEAS — Load Effective Address into S

S ← EA

LEAS  n,R

Description

Loads the indexed effective address into S. No flags are affected — unlike LEAX/LEAY, LEAS does not update Z. Commonly used to adjust the stack pointer: LEAS n,S deallocates n bytes of stack frame.

Condition codes

EFHINZVC
––––––––

Addressing modes

ModeSyntaxOpcode~#
IndexedLEAS n,R324+2+

Examples

        LEAS   2,S         * pop 2 bytes off the S stack
        LEAS   -8,S        * reserve an 8-byte local frame
