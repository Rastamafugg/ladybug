6809 · Branch (short)

BGT — Branch if Greater Than (signed)

if Z = 0 AND (N XOR V) = 0: branch

BGT  <label>

Description

Signed greater-than: branches after CMP when r > m (signed).

Condition codes

EFHINZVC
