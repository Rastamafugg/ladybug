6809 · Load / Store

LDB — Load Accumulator B

B ← (M)

LDB  <operand>

Description

Loads the contents of the addressed memory location into the 8-bit accumulator B. The N and Z flags reflect the loaded value; V is cleared; H, I, F, C are unaffected.

Use LDA for the other half of D, or LDD to load both halves with one instruction.

Condition codes

EFHINZVC
––––↕↕0–
  • N — set if bit 7 of the loaded value is 1.
  • Z — set if the loaded value is zero.
  • V — always cleared.
  • H, I, F, C — unaffected.

Addressing modes

ModeSyntaxOpcode~#
Immediate LDB #n C622
Direct LDB <nD642
Indexed LDB n,R E64+2+
Extended LDB n F653

~ = clock cycles. # = instruction bytes. Indexed mode adds 0–4 cycles and 0–2 bytes depending on the post-byte form. See addressing modes.

Examples

        LDB   #0           * B <- 0
        LDB   <count       * direct page load
        LDB   ,X+          * post-increment indexed
        LDB   sprite_id    * extended
