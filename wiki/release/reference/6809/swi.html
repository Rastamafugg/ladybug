SWI / SWI2 / SWI3 — Software Interrupt

stack entire state; PC ← (vector)

SWI
SWI2
SWI3

Description

Each software interrupt sets the E bit, pushes the entire register set (PC, U, Y, X, DP, B, A, CC) onto the S stack, then loads PC from a fixed vector. The handler returns with RTI, which restores the full frame.

SWI also sets F and I, masking further interrupts; it vectors through $FFFA. SWI2 (vector $FFF4) and SWI3 (vector $FFF2) do not set the masks, so they can be used as system calls without disabling FIRQ/IRQ.

Condition codes

EFHINZVC
11*–1*––––
  • 1 — set.
  • * — F and I are set by SWI only; SWI2 and SWI3 leave them unchanged.
