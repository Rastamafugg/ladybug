6809 · Load / Store

STA — Store Accumulator A

M ← A

STA  <operand>

Description

Stores the contents of accumulator A into the addressed memory location. N and Z reflect the stored value; V is cleared. No immediate mode — the destination must be a memory location.

Condition codes

EFHINZVC
––––↕↕0–

Addressing modes

ModeSyntaxOpcode~#
Direct STA <n9742
Indexed STA n,R A74+2+
ExtendedSTA n B753

Examples

        STA   <palette     * direct page
        STA   ,X+          * (X) <- A, X = X+1
        STA   $FF22        * write PIA2 port B
