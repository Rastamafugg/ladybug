6809 · Branch (short)

BPL — Branch if Plus

if N = 0: branch

BPL  <label>

Description

Branches when N is clear (most recent result was non-negative). Tests the sign bit, not "≥ 0 signed" — those agree only when no overflow occurred. Use BGE for proper signed comparison.
