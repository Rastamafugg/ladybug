SYNC — Synchronize to Interrupt

halt until an interrupt is asserted

SYNC

Description

Stops the processor and floats the bus until an interrupt line goes active. If the asserted interrupt is masked (or lasts fewer than three cycles), execution resumes inline at the instruction after SYNC; otherwise the matching interrupt is taken normally. SYNC enables tight, low-latency synchronization to an external event without polling.

On the CoCo 3 this is mainly relevant for cycle-exact synchronization to a hardware interrupt source; see the platform IRQ notes for usage caveats.
