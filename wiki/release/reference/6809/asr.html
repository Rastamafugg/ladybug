6809 · Shift / Rotate

ASR / ASRA / ASRB — Arithmetic Shift Right

b7 stays; b7→b6→…→b0→C (signed divide by 2)

ASR  <operand>
ASRA
ASRB

Description

Shifts the operand right one bit, replicating bit 7 (sign extension). Bit 0 goes into C. Equivalent to a signed divide by 2 with rounding toward negative infinity.

Condition codes

EFHINZVC
––U–↕↕–↕
  • C — old bit 0.
  • V — unaffected.
  • H — undefined.

Examples

        ASRA               * signed A / 2
        ASRA               * signed A / 4
        ASR   <dy          * halve dy preserving sign
