6809 · Branch (short)

BCS / BLO — Branch if Carry Set / Lower

if C = 1: branch

BCS  <label>
BLO  <label>

Description

Branches when carry is set. BCS and BLO are mnemonic aliases for the same opcode ($25). After an unsigned compare, BLO reads as "branch if r < m"; after an arithmetic op, BCS reads as "branch if carry out".
