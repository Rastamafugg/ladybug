6809 · Arithmetic

MUL — Unsigned Multiply

D ← A × B (unsigned)

MUL

Description

Performs an 8-bit-by-8-bit unsigned multiply of A and B, storing the 16-bit product in D (A is the high byte, B the low byte). Inherent mode only — no operand. 11 cycles regardless of operand values.

For signed multiplication, the operands must be sign-corrected by the caller. C is set if bit 7 of the product (i.e. bit 7 of B) is 1, which lets the caller round a fractional result with ADCA #0.

Condition codes

EFHINZVC
–––––↕–↕
  • Z — set if the 16-bit product is zero.
  • C — set if bit 7 of B (bit 7 of the low byte of the product) is 1; for rounding.

Addressing modes

ModeSyntaxOpcode~#
InherentMUL3D111

Examples

        LDA   #row_w       * row width
        LDB   row          * Y coordinate
        MUL                * D = row * row_w
        ADDD  #screen      * D = address of row start
        TFR   D,X
