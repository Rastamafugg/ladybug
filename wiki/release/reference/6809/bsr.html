6809 · Branch (short)

BSR — Branch to Subroutine

push PC; PC ← PC + signed 8-bit offset

BSR  <label>

Description

Pushes the return address (the instruction after BSR) onto the S stack, then branches PC-relative to the target. Pair with RTS. For targets out of 8-bit reach use LBSR; for absolute addresses use JSR.
