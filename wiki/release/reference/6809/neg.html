6809 · Arithmetic

NEG / NEGA / NEGB — Two's-Complement Negate

operand ← 0 − operand (= ¯operand + 1)

NEG  <operand>
NEGA
NEGB

Description

Replaces the operand with its two's-complement negation. NEGA and NEGB negate the accumulators in-place; NEG negates a memory operand via direct, indexed, or extended addressing.

Edge case: negating $80 leaves the value unchanged ($80 has no positive counterpart in 8-bit two's complement); V is set and C is set in that case. Negating $00 yields $00 and clears C; for any other value C is set.

Condition codes

EFHINZVC
––U–↕↕↕↕
  • V — set if the operand was $80.
  • C — set if the operand was not zero.
  • H — undefined.
