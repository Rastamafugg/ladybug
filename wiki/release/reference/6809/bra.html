6809 · Branch (short)

BRA — Branch Always

PC ← PC + signed 8-bit offset (unconditional)

BRA  <label>

Description

Unconditional short branch. The 8-bit signed offset reaches −126 to +129 bytes from the branch instruction's address. For longer reach use LBRA or JMP.

Condition codes

EFHINZVC
