6809 · Shift / Rotate

LSR / LSRA / LSRB — Logical Shift Right

0 → b7 → … → b0 → C (unsigned divide by 2)

LSR  <operand>
LSRA
LSRB

Description

Shifts the operand right one bit, shifting 0 into bit 7. Bit 0 goes into C. Equivalent to unsigned divide by 2. N is always cleared (the new bit 7 is 0).
