6809 · Register transfer

EXG — Exchange Registers

R1 ↔ R2

EXG  R1,R2

Description

Swaps the contents of two registers in a single instruction. A post-byte names both via 4-bit codes; the two registers must be the same size — 16-bit (D, X, Y, U, S, PC) or 8-bit (A, B, CC, DP).

Compared with TFR, EXG modifies both operands. It is handy for rotating pointers or temporarily parking a value without touching memory.

Condition codes

EFHINZVC
––––––––
  • Flags are unchanged unless CC is one of the operands, in which case it takes the exchanged value.
