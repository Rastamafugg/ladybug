SBCB — Subtract with Carry from B

B ← B − (M) − C

SBCB  <operand>

Description

Subtracts (M) + C from B.

Condition codes

EFHINZVC
––U–↕↕↕↕

Examples

        SBCB   #0          * absorb pending borrow
