6809 · Arithmetic

ADCA — Add with Carry to A

A ← A + (M) + C

ADCA  <operand>

Description

Adds (M) + C to A and stores the result in A. Used to extend multi-byte addition past the low byte (ADDA for the low byte, ADCA for each higher byte).

EFHINZVC

        ADCA   hi_b        * propagate carry into A
