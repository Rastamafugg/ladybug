6809 · Load / Store

LEAX — Load Effective Address into X

X ← EA

LEAX  n,R

Description

Computes the effective address of the indexed operand and loads it (the address itself, not the value at that address) into X. Only the Z flag is updated, allowing LEAX to be used after loops that decrement and check for zero (LEAX -1,X + BNE).

Indexed mode only — there is no immediate, direct, or extended form. See addressing modes for the full post-byte table.

Condition codes

EFHINZVC
–––––↕––
  • Z — set if the resulting address is zero.
  • All other flags unaffected.

Addressing modes

ModeSyntaxOpcode~#
IndexedLEAX n,R304+2+

Examples

        LEAX   1,X         * X = X + 1
        LEAX   -1,X        * X = X - 1; Z set if zero (loop guard)
        LEAX   table,PCR   * PC-relative: X <- absolute addr of table
        LEAX   D,X         * X = X + D (signed)
