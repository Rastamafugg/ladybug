6809 · Branch (long)

LBLT — Long Branch if Less Than (signed)

if N XOR V = 1: PC ← PC + signed 16-bit offset

LBLT  <label>

Description

Long-form of BLT: signed less-than after a compare (r < m), reaching anywhere in the 64K address space. Taken branches cost one extra cycle.

Condition codes

EFHINZVC
