PSHS — Push Registers onto S Stack

push the selected register set onto S

PSHS  <register list>

Description

Pushes any subset of PC, U, Y, X, DP, B, A, CC onto the hardware (S) stack. A post-byte selects which registers; they are always stored in a fixed order (high-address registers first), regardless of how the list is written. PSHS D pushes A then B.

The mirror pull is PULS. Use PSHU to push onto the user (U) stack instead.
