6809 · Compare / Test

CMPS — Compare S with Memory

S − (M:M+1); flags set, S unchanged

CMPS  <operand>

Description

16-bit compare of S. Uses the $11 page-3 prefix. Useful for stack-overflow guards: compare S against a low-water-mark address.

Condition codes

EFHINZVC
