6809 · Branch (long)

LBCS / LBLO — Long Branch if Carry Set

if C = 1: PC ← PC + signed 16-bit offset

LBCS  <label>
LBLO  <label>

Description

Long-form of BCS/BLO: branches when C = 1. LBLO (lower) is the same opcode, read as unsigned r < m after a compare. Reaches anywhere in the 64K address space; taken branches cost one extra cycle.

Condition codes

EFHINZVC
