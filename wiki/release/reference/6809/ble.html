6809 · Branch (short)

BLE — Branch if Less or Equal (signed)

if Z = 1 OR (N XOR V) = 1: branch

BLE  <label>

Description

Signed less-or-equal: branches after CMP when r ≤ m (signed).

EFHINZVC
