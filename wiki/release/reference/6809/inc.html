6809 · Arithmetic

INC / INCA / INCB — Increment

operand ← operand + 1

INC  <operand>
INCA
INCB

Description

Adds 1 to the operand in place. C is not affected. V is set if the operand was $7F (signed overflow).

EFHINZVC
