CWAI — Clear CC and Wait for Interrupt

CC ← CC ∧ IMM; stack entire state; wait

CWAI  #<mask>

Description

ANDs CC with the immediate mask (used to pre-clear the I and/or F interrupt-enable bits), sets the E bit, then pushes the entire register set onto the S stack and halts until an interrupt arrives. Because the machine state is stacked before waiting, the eventual interrupt is entered with reduced latency — the handler need not re-stack.

The companion RTI then restores the full frame. Common idiom: CWAI #$EF clears I to allow IRQ while waiting.

Condition codes

EFHINZVC
1↕↕↕↕↕↕↕
  • 1 — E set (entire state stacked).
  • ↕ — ANDed with the corresponding bit of the immediate mask (a 0 in the mask clears that flag; a 1 leaves it unchanged).
