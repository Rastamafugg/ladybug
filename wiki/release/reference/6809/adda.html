6809 · Arithmetic

ADDA — Add to Accumulator A

A ← A + (M)

ADDA  <operand>

Description

Adds the 8-bit memory operand to A and stores the result in A. Updates H, N, Z, V, and C from the unsigned 8-bit addition.

Condition codes

EFHINZVC
––↕–↕↕↕↕
  • H — carry from bit 3 (for BCD via DAA).
  • V — set on signed overflow.
  • C — set on unsigned carry out of bit 7.

Addressing modes

ModeSyntaxOpcode~#
ImmediateADDA #n 8B22
Direct ADDA <n9B42
Indexed ADDA n,R AB4+2+
Extended ADDA n BB53

Examples

        ADDA   #1          * A = A + 1
        ADDA   <delta
        ADDA   ,X+
