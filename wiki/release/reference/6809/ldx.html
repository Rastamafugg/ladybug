6809 · Load / Store

LDX — Load Index Register X

X ← (M:M+1)

LDX  <operand>

Description

Loads a 16-bit value from M:M+1 into index register X. N and Z reflect the 16-bit result; V is cleared.

Use immediate (LDX #ptr) to set up a base address before indexed addressing.

Condition codes

EFHINZVC
––––↕↕0–

Addressing modes

ModeSyntaxOpcode~#
Immediate LDX #nn 8E33
Direct LDX <n9E52
Indexed LDX n,R AE5+2+
Extended LDX n BE63

Examples

        LDX   #sprite_tbl  * X <- address of table
        LDX   ,Y++         * X <- (Y), Y = Y+2
        LDX   <cur_actor   * 16-bit DP load
