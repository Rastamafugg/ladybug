RTI — Return from Interrupt

restore machine state from S; PC ← pulled from S

RTI

Description

Ends an interrupt service routine by restoring the registers an interrupt stacked. It first pulls CC; if the pulled E (entire) bit is 1, the full register set (CC, A, B, DP, X, Y, U, PC) is restored — 15 cycles. If E = 0 (a fast FIRQ entry) only CC and PC are restored — 6 cycles.

Because CC is reloaded from the stack, all condition codes (and the I/F interrupt masks) take whatever value was saved at interrupt entry.

Condition codes

EFHINZVC
↕↕↕↕↕↕↕↕
  • ↕ — restored from the stacked CC value.
