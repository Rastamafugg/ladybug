6809 · Arithmetic

DAA — Decimal Adjust A

A ← A adjusted for BCD after add

DAA

Description

Adjusts the contents of A to the correct BCD result after a binary add of two BCD values. Uses the H and C flags set by the preceding ADD/ADC. Only valid after an addition — there is no equivalent for subtraction.

Typical use: score counters represented as packed BCD so each nibble is a decimal digit.

Condition codes

EFHINZVC
––––↕↕0↕
  • C — set if the BCD result overflowed past 99; chain into the next byte with ADCA #0 + DAA.

Addressing modes

ModeSyntaxOpcode~#
InherentDAA1921

Examples

        LDA   <score_lo    * packed BCD
        ADDA  #$10         * add 10 points
        DAA                * fix up nibbles
        STA   <score_lo
        LDA   <score_hi
        ADCA  #0
        DAA
        STA   <score_hi
