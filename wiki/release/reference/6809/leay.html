LEAY — Load Effective Address into Y

Y ← EA

LEAY  n,R

Description

Computes the indexed effective address and loads it into Y. Like LEAX, only Z is updated — useful for LEAY -1,Y + BNE loops.

Condition codes

EFHINZVC
–––––↕––

Addressing modes

ModeSyntaxOpcode~#
IndexedLEAY n,R314+2+

Examples

        LEAY   $20,Y       * Y = Y + $20
        LEAY   B,X         * Y = X + B (unsigned-extended)
