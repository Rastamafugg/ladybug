6809 · Arithmetic

SUBD — Subtract from D

D ← D − (M:M+1)

SUBD  <operand>

Description

Subtracts the 16-bit operand from D and stores the result in D. There is no SBCD — for multi-precision subtraction use SUBD for the low 16 bits and propagate the borrow manually.
