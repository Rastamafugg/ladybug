6809 · programming model

Registers

Programming model for the MC6809E / MC68B09E — accumulators, index and stack registers, PC, DP, and the condition-code register.

  • A / B — 8-bit accumulators; D is the 16-bit concatenation A:B. Any 16-bit load through D destroys both halves.
  • X, Y, U, S — full 16-bit pointer / index registers. All four work with every indexed addressing form, so the 6809 effectively has four independent index regs.
  • S is the hardware stack used by the interrupt machinery. U is reserved for user-stack discipline.
  • PC — program counter.
  • DP — direct-page register, providing the upper byte of every direct-page address. Setting DP lets a hot variable area access in 2-byte / 4-cycle DP-relative form instead of 3-byte / 5-cycle extended.
  • CC — condition code register, see condition codes.

Interrupt sequence summary

RTI inspects the popped CC: if E was set, pops everything; if E was clear (FIRQ path), pops only PC. Implication: an IRQ handler that wants to share state with FIRQ must do its own pushes — FIRQ does not save A/B/X/etc.

In ROM the vectors at $FFF2-FFFF are mirrored to RAM long-branch trampolines at $FEEE-FEFF (primary jump table) and to legacy 6-byte JMPs at $0100-$010F (secondary jump table). Both tables are writable.

Register codes (TFR / EXG postbyte)

TFR copies source→dest; EXG swaps. Postbyte holds two register codes (high nybble + low nybble):

Push / pull postbyte bit map

PSHS / PSHU / PULS / PULU postbyte (bit positions, high→low):

bit 7 = PC, 6 = S/U, 5 = Y, 4 = X, 3 = DP, 2 = B, 1 = A, 0 = CC

Cycle cost is 5 + 1 per byte transferred. PULS / PULU restore CC if it's in the postbyte mask.
