6809 · Branch (short)

BNE — Branch if Not Equal

if Z = 0: PC ← PC + signed 8-bit offset

BNE  <label>

Description

Branches when Z is clear. The standard loop tail: DECB + BNE loop.

Condition codes

EFHINZVC
