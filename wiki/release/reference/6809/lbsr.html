6809 · Branch (long)

LBSR — Long Branch to Subroutine

push PC; PC ← PC + signed 16-bit offset

LBSR  <label>

Description

Pushes the return address onto the S stack, then branches PC-relative with a 16-bit signed offset, reaching anywhere in the 64K address space. Pair with RTS. Use BSR for nearby targets, JSR for absolute addresses.

Unlike BSR, LBSR has no single-byte opcode — it is opcode 17 with no page prefix.
