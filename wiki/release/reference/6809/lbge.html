6809 · Branch (long)

LBGE — Long Branch if Greater or Equal (signed)

if N XOR V = 0: PC ← PC + signed 16-bit offset

LBGE  <label>

Description

Long-form of BGE: signed greater-or-equal after a compare (r ≥ m), reaching anywhere in the 64K address space. Taken branches cost one extra cycle.

Condition codes

EFHINZVC
