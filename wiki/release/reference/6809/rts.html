RTS — Return from Subroutine

PC ← pulled from S

RTS

Description

Pulls a 16-bit return address off the S stack into PC, resuming the caller. It is the counterpart to JSR, BSR, and LBSR. Every subroutine entered by one of those must balance its own stack pushes before executing RTS.
