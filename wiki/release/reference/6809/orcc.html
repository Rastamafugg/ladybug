ORCC — OR Immediate with CC

CC ← CC OR #imm

ORCC  #mask

Description

Sets the specified bits in the condition code register by ORing with an immediate 8-bit mask. The canonical way to set the IRQ mask: ORCC #$50 sets I and F (disabling IRQ and FIRQ).

Condition codes

EFHINZVC
Each bit set if the corresponding mask bit is 1.

Addressing modes

ModeSyntaxOpcode~#
ImmediateORCC #n1A32

Examples

        ORCC  #$50         * disable IRQ and FIRQ
        ORCC  #$01         * set carry
