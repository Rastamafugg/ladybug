PULU — Pull Registers from U Stack

pull the selected register set from U

PULU  <register list>

Description

Identical to PULS but uses the user (U) stack pointer, reversing a PSHU. The register list uses S in place of U. Pulling PC performs a return through the U stack.

Condition codes

EFHINZVC
↕↕↕↕↕↕↕↕
  • ↕ — affected only if CC is in the pull list (it is then loaded from the stack); otherwise all flags are unchanged.

Addressing modes

ModeSyntaxOpcode~#
InherentPULU list375+2

Examples

        PULU  D,X           * pull from the user data stack
