JSR — Jump to Subroutine

push PC; PC ← EA

JSR  <operand>

Description

Pushes the return address (the instruction after JSR) onto the S stack, then jumps to the effective address. Pair with RTS. Use BSR/LBSR for PC-relative subroutine calls.

Like JMP, the target is absolute or computed, so indexed mode allows table-driven subroutine dispatch.
