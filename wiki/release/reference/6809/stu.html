6809 · Load / Store

STU — Store User Stack Pointer

M:M+1 ← U

STU  <operand>

Description

Stores the user stack pointer U into M:M+1. N and Z reflect the 16-bit stored value; V is cleared.

Condition codes

EFHINZVC
––––↕↕0–

Addressing modes

ModeSyntaxOpcode~#
Direct STU <nDF52
Indexed STU n,R EF5+2+
ExtendedSTU n FF63

Examples

        STU   <save_u
