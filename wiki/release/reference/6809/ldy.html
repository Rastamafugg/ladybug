6809 · Load / Store

LDY — Load Index Register Y

Y ← (M:M+1)

LDY  <operand>

Description

Loads a 16-bit value from M:M+1 into index register Y. N and Z reflect the 16-bit result; V is cleared.

Y-prefixed instructions use the $10 page-2 prefix, so they are one byte longer and one cycle slower than the matching LDX form.

Examples

        LDY   #screen      * Y <- video base
        LDY   ,X++         * Y <- (X), X = X+2
