6809 · Load / Store

STS — Store Hardware Stack Pointer

M:M+1 ← S

STS  <operand>

Description

Stores the hardware stack pointer S into M:M+1. Uses the $10 page-2 prefix. N and Z reflect the 16-bit stored value; V is cleared.

EFHINZVC
