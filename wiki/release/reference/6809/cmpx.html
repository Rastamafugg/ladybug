CMPX — Compare X with Memory

X − (M:M+1); flags set, X unchanged

CMPX  <operand>

Description

16-bit compare of X with (M:M+1). Note: CMPX uses no prefix — it is the only 16-bit compare on the base page-1 opcode space, making it 1 byte / 1 cycle cheaper than CMPY/CMPU/CMPS/CMPD on every mode.
