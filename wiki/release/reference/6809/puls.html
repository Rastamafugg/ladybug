PULS — Pull Registers from S Stack

pull the selected register set from S

PULS  <register list>

Description

Pulls any subset of CC, A, B, DP, X, Y, U, PC off the hardware (S) stack, in the reverse order to PSHS. Pulling PC effects a return — PULS PC is equivalent to RTS, and PULS A,B,X,PC restores registers and returns in one instruction.

Condition codes

EFHINZVC
↕↕↕↕↕↕↕↕
  • ↕ — affected only if CC is in the pull list (it is then loaded from the stack); otherwise all flags are unchanged.
