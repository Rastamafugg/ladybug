COM / COMA / COMB — One's-Complement

operand ← NOT operand

COM  <operand>
COMA
COMB

Description

Inverts every bit of the operand (one's complement). C is always set to 1 by COM — a quirk that lets COM substitute for a "load FF and store" with carry-set as a side effect. V is cleared.
