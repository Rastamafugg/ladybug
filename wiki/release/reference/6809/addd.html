6809 · Arithmetic

ADDD — Add to Accumulator D

D ← D + (M:M+1)

ADDD  <operand>

Description

Adds the 16-bit memory operand to D and stores the result in D. H is unaffected (16-bit add has no half-carry semantics); N, Z, V, C reflect the 16-bit result.
