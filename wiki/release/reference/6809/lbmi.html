6809 · Branch (long)

LBMI — Long Branch if Minus

if N = 1: PC ← PC + signed 16-bit offset

LBMI  <label>

Description

Long-form of BMI: branches when N = 1 (result negative), reaching anywhere in the 64K address space. Taken branches cost one extra cycle.

Condition codes

EFHINZVC
