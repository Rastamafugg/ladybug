6809 · Branch (short)

BRN — Branch Never

no branch taken; consumes 3 cycles and 2 bytes

BRN  <label>

Description

Always falls through. Used as a 2-byte / 3-cycle no-op for timing or as a self-patchable branch target (assemble as BRN, patch the opcode to BRA at runtime to enable).
