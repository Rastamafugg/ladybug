ANDCC — AND Immediate with CC

CC ← CC AND #imm

ANDCC  #mask

Description

Clears the specified bits in the condition code register by ANDing with an immediate 8-bit mask. The canonical way to clear the IRQ mask: ANDCC #$AF clears bits I and F (enabling IRQ and FIRQ).

See condition codes for the bit layout of CC.

Condition codes

EFHINZVC
Each bit cleared if the corresponding mask bit is 0.

Addressing modes

ModeSyntaxOpcode~#
ImmediateANDCC #n1C32

Examples

        ANDCC  #$AF        * clear I and F (enable interrupts)
        ANDCC  #$FE        * clear carry
