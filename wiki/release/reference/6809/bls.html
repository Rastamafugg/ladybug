6809 · Branch (short)

BLS — Branch if Lower or Same (unsigned)

if C = 1 OR Z = 1: branch

BLS  <label>

Description

Unsigned less-or-equal: branches after a CMP when r ≤ m (unsigned).

EFHINZVC
