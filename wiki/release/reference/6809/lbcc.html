6809 · Branch (long)

LBCC / LBHS — Long Branch if Carry Clear

if C = 0: PC ← PC + signed 16-bit offset

LBCC  <label>
LBHS  <label>

Description

Long-form of BCC/BHS: branches when C = 0. LBHS (higher-or-same) is the same opcode, read as unsigned r ≥ m after a compare. Reaches anywhere in the 64K address space; taken branches cost one extra cycle.

Condition codes

EFHINZVC
