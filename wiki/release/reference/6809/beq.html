6809 · Branch (short)

BEQ — Branch if Equal

if Z = 1: PC ← PC + signed 8-bit offset

BEQ  <label>

Description

Branches when the Z flag is set — typically after a CMP that found equality, or after a load/decrement that produced zero.

Condition codes

EFHINZVC
––––––––

        CMPA  #' '
        BEQ   is_space
