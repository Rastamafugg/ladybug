6809 · Shift / Rotate

ROR / RORA / RORB — Rotate Right Through Carry

new C ← b0; b1→b0, …, b7→b6; old C → b7

ROR  <operand>
RORA
RORB

Description

9-bit rotation right through C. Used to chain shifts: 16-bit unsigned right shift in D is LSRA then RORB; 16-bit arithmetic (signed) right shift is ASRA then RORB.
