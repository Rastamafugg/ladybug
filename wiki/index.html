About this wiki

Ladybug is a 6809 assembly-language port of the 1981 Universal arcade game Lady Bug to the Tandy Color Computer 3 (512K), targeting native hardware with no operating system. This wiki is the project's source of truth for game design, platform constraints, and implementation choices. It is maintained by the AI authoring agent — see CLAUDE.md for the authoring rules.

Hand-authored HTML. No build step. The release branch is served by the project's web app as contextual help.
